검사기: `python study/check_style.py` (고치기: `--fix`, 테스트만: `--test`)

대상은 **내 풀이(`Python/**/*.py`)** 뿐이다. `study/ref/` 는 공유받아 검증된 코드라 **건드리지 않는다**
(`260921-하네스스킬.md`: "사람들이 공유한 것. 검증됨. 고치지 말 것").

## 1. 입력은 항상 이 두 줄로 시작한다

```python
import sys
input = sys.stdin.readline
```

**왜 통일하나** — 속도 때문이 아니다. "이 문제는 입력이 크나?" 를 **매번 판단하지 않기 위해서**다.
절대 느려지지 않으니 손해도 없다.

실측 (20만 줄 입력):

| 방식 | 시간 |
|---|---|
| 그냥 `input()` | 0.184s |
| `sys.stdin.readline` | 0.098s — 약 1.9배 |
| `sys.stdin.read().split()` | 0.069s — 약 2.7배 |

**2배지 10배가 아니다.** Bronze 에서는 차이가 없고, Silver/Gold 그래프 문제(N이 10⁵~10⁶)에서
AC 와 TLE 를 가른다. 가장 빠른 `read().split()` 은 **쓰지 않는다** — 인덱스를 손으로 세야 해서
실수가 늘고, 얻는 건 0.03초다.

## 2. `\n` 규칙 — 외울 건 이거 하나다

`readline` 은 줄 끝의 `\n` 을 **떼어주지 않는다.**

| 쓰는 법 | 안전? | 왜 |
|---|---|---|
| `n = int(input())` | ✅ | `int("5\n")` = 5. `int` 가 `\n` 을 무시한다 |
| `a = list(map(int, input().split()))` | ✅ | `.split()` 이 `\n` 을 떼어낸다 |
| `s = input()` | ❌ | **`s` 에 `\n` 이 남는다** |

> **`int()` 나 `.split()` 을 거치면 안전하다. 줄을 문자열 그대로 쓸 때만 `.rstrip()`.**

이걸 안 지키면 **에러가 안 나고 답만 조용히 틀린다.** 실제로 우리 저장소에 있었던 것들:

| 문제 | `\n` 이 남으면 |
|---|---|
| 1259 팰린드롬수 | `n == '0'` 이 `'0\n'` 과 안 맞아 **`break` 를 못 해 무한루프** |
| 16172 나는 친구가 적다 | `K in S` 가 어긋나 오답 |
| 15829 Hashing | `ord('\n') - 96` = **-86** 이 해시 합에 섞인다 |

## 3. `range(n)` 과 `range(1, n+1)` 은 통일하지 않는다

문제마다 맞는 게 다르다. **판단 규칙**만 고정한다.

| 상황 | 이렇게 |
|---|---|
| 반복 변수를 **안 쓴다** | `for _ in range(n)` — 예외 없이 |
| 0부터 세는 인덱스로 쓴다 | `for i in range(n)` |
| 문제가 1번부터 번호를 붙인다 (정점·학생 번호) | `for i in range(1, n+1)` |

`for _ in range(1, n+1)` 은 **변수를 안 쓰는데 시작점이 1** 이라 순수한 잡음이다. 읽는 사람이
"왜 1부터지?" 하고 멈춘다. 검사기가 `W1` 으로 알려준다(막지는 않는다).

진짜 중요한 통일은 이쪽이다.

> **1-based 문제는 처음부터 끝까지 1-based 로.** 배열을 `[0] * (n+1)` 로 잡고 1번부터 쓴다.

0-based 배열에 1-based 입력을 섞는 것이 off-by-one 공장이다.

## 검사기가 보는 것

| 코드 | 뜻 | `--fix` 가 고치나 |
|---|---|---|
| `E1` | `input(` 을 쓰는데 preamble 이 없다 | ✅ |
| `E2` | `x = input()` 로 줄을 문자열째 받는다 | ✅ `.rstrip()` 추가 |
| `E3` | preamble 은 있는데 `import sys` 가 없다 | ✅ |
| `E4` | `input("...")` — readline 은 인자를 못 받는다(TypeError) | ❌ 사람이 봐야 함 |
| `W1` | `for _ in range(1, ...)` | ❌ 알려만 줌 |

**`E1` 만 고치고 `E2` 를 놔두면 멀쩡했던 코드가 틀린다.** 그래서 `--fix` 는 셋을 **같이** 고친다.
하나만 고르는 선택지를 두지 않았다.

## 안전장치

`--fix` 는 고치기 **전** 출력을 먼저 기록하고, 고친 **뒤** 다시 돌려서 한 글자라도 달라지면
그 파일을 **되돌린다.** 그래서 AC 코드를 깨뜨릴 수 없다.

비교 대상은 저장된 정답(`output*.txt`)이 **아니라 바꾸기 전 내 출력**이다. 저장본이 절대 기준이
아니기 때문이다 — 실제로 두 건이 원래부터 안 맞는다.

| 문제 | 저장본 | 내 출력 | 판단 |
|---|---|---|---|
| 1546 평균 | `66.666667` | `66.66666666666667` | 문제 없음. BOJ 는 오차를 허용한다 |
| 33701 새천년관 | `kukugwan` | `nkukugwan` | **오타로 보인다** — 확인 필요 |

테스트가 없는 문제는 증명할 수 없으므로 `--fix` 가 **건너뛴다.**
