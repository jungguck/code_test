# QWEN에게 줄 프롬프트 — 카드 만들기

아래 `=====` 사이를 **그대로 복사해서** QWEN에게 붙여넣는다.
`{번호}` `{제목}` `{난이도}` `{분류}` `{코드}` 다섯 군데만 바꿔 넣으면 된다.

한 번에 **한 장씩** 시킨다. 74장을 한꺼번에 시키면 품질이 무너진다.

=====
너는 코딩테스트 공부용 "답지 카드"를 만드는 역할이다.

읽는 사람은 **파이썬 문법도 아직 헷갈리는 초보**다.
이 사람은 문제를 스스로 풀지 못하고, **정답 코드를 읽고 패턴을 외우려고** 한다.
그러니 "이렇게 푼다" 가 아니라 **"왜 이렇게 푸는지, 이 줄이 무슨 뜻인지"** 를 써야 한다.

## 주어지는 것

- 문제 번호: {번호}
- 문제 제목: {제목}
- 난이도: {난이도}
- 분류: {분류}          (01_graph = 그래프탐색·완전탐색 / 02_ds = 자료구조 / 03_dp = DP)
- 정답 코드:
```python
{코드}
```

## 절대 규칙

1. **코드를 고치지 마라.** 코드는 이미 검증된 정답이다. 너는 설명만 붙인다.
2. **문제 지문을 지어내지 마라.** 지문은 **코드에서 읽어낼 수 있는 것**으로 복원한다.
   - 입력 형식은 코드의 `input()` 호출 순서를 **그대로** 따른다
   - 출력 형식은 코드의 `print()` 를 **그대로** 따른다
   - 이 규칙을 지키면 지문과 정답이 어긋날 수가 없다
3. 코드만 봐서는 알 수 없는 것(N의 최대값 같은 제약 조건)은 **추측하지 말고** 이렇게 표시한다.
   ```
   <!-- 확인필요: N의 최대 범위를 코드만으로는 알 수 없음 -->
   ```
4. **버그 항목은 함부로 만들지 마라.** `## ⚠️ 이 코드의 버그` 는
   **틀리는 입력 + 그때의 잘못된 출력 + 올바른 출력**을 구체적으로 댈 수 있을 때만 추가한다.
   확신이 없으면 **그 항목을 아예 넣지 마라.** (억지로 만들면 없는 버그를 지어내게 된다)
5. 파이썬 특유의 문법이 코드에 나오면 **반드시 풀어서 설명**한다.
   `for ... else` / 리스트 컴프리헨션 / 삼항식 / `*` 언패킹 / 슬라이싱 / `enumerate` / `zip` 등.
   초보는 이것 때문에 코드를 못 읽는다.
6. 전부 **한국어**로 쓴다.
7. 아래 **일곱 개 항목을 빠짐없이** 넣는다. 항목 제목을 바꾸지 마라.

## 문제
계단이 N개 있고, 각 계단마다 점수가 적혀 있다.
바닥에서 출발해 꼭대기까지 올라가면서 밟은 계단의 점수를 모두 더한다. 규칙 세 가지:
1. 한 번에 1칸 또는 2칸만 오를 수 있다
2. 연속된 세 계단을 모두 밟으면 안 된다
3. 마지막 계단은 반드시 밟아야 한다
얻을 수 있는 점수의 최댓값을 구하라.

## 입력
- 첫째 줄: N (1 ≤ N ≤ 300)
- 다음 N줄: 각 계단의 점수 (10,000 이하 자연수)

## 출력
- 최대 점수 하나

## 예제
```
입력   출력
6      75
10
20
15
25
10
20
```
`10 + 20 + 25 + 20 = 75` — 3번(15)과 5번(10)을 건너뛴다.

## 풀이 아이디어
**핵심 질문: "i번째 계단을 밟았다면, 직전 계단도 밟았나?"**
`dp[i]` = i번째 계단을 밟았을 때의 최대 점수. i에 도착하는 방법은 두 가지뿐이다.
```
① 2칸 점프(직전 안 밟음)      dp[i] = dp[i-2] + 점수[i]
② 1칸(직전 밟음→i-2는 못 밟음) dp[i] = dp[i-3] + 점수[i-1] + 점수[i]
```
둘 중 큰 쪽: `dp[i] = max(dp[i-2], dp[i-3]+점수[i-1]) + 점수[i]`

## 코드 따라가기
```python
dp = [lst[0], lst[0]+lst[1], max(lst[0], lst[1])+lst[2]]
```
`dp[i-3]` 이 음수 인덱스가 되지 않게 앞 세 칸은 손으로 채운다.
```python
print(dp[-1])
```
규칙 3 때문에 마지막을 반드시 밟으므로 `max(dp)` 가 아니라 `dp[-1]` 이다.

## 외울 것
> **"연속 3개 금지" → 직전을 밟았는지로 경우를 가른다 → `dp[i-2]` vs `dp[i-3]+전칸`.**
> 마지막을 꼭 밟아야 하면 답은 `max(dp)` 가 아니라 `dp[-1]`.

## 만든 뒤에 할 일

1. 결과를 `study/cards/{분류}/{번호}.md` 로 저장한다
2. 검사한다
   ```
