## 문제
두 개의 자연수를 입력받아, 이 두 수의 **최대공약수(GCD)**와 **최소공배수(LCM)**를 구하는 문제이다.

## 입력
- 첫째 줄: 두 개의 자연수 `a`, `b` (1 ≤ a, b ≤ 10,000)

## 출력
- 첫째 줄: 최대공약수
- 둘째 줄: 최소공배수

## 예제
```
입력          출력
6 8           2
              24
```
6과 8의 최대공약수는 2이고, 최소공배수는 24이다.

## 풀이 아이디어
**핵심 질문: "두 수의 최대공약수를 어떻게 효율적으로 구할까?"**

1. **유클리드 호제법**: 두 수 `a`, `b`에 대해 `a % b`를 반복적으로 구하면, 나머지가 0이 될 때의 `a`가 최대공약수가 된다.
   - 예: `gcd(6, 8)` → `gcd(8, 6)` → `gcd(6, 2)` → `gcd(2, 0)` → 답: 2
2. **최소공배수 공식**: 두 수의 곱을 최대공약수로 나누면 최소공배수가 된다.
   - `LCM(a, b) = (a * b) / GCD(a, b)`
   - 예: `(6 * 8) / 2 = 24`

## 코드 따라가기
```python
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a
```
- `while b != 0:` : `b`가 0이 될 때까지 반복한다.
- `a, b = b, a % b` : **동시 대입** 문법이다.
  - 왼쪽의 `a`에는 오른쪽의 `b`가, 왼쪽의 `b`에는 오른쪽의 `a % b`가 들어간다.
  - 즉, `a`는 원래의 `b` 값이 되고, `b`는 원래의 `a`를 `b`로 나눈 나머지가 된다.
  - 이 과정이 반복되면 결국 `b`가 0이 되고, 그때의 `a`가 최대공약수가 된다.

```python
a, b = map(int, input().split())
```
- `input().split()` : 입력받은 문자열을 공백 기준으로 잘라서 리스트로 만든다.
- `map(int, ...)` : 리스트의 각 요소를 정수로 변환한다.
- `a, b = ...` : 변환된 두 값을 각각 `a`, `b` 변수에 저장한다.

```python
g = gcd(a, b)
l = a * b // g
```
- `g = gcd(a, b)` : 위에서 정의한 `gcd` 함수를 호출하여 최대공약수를 구한다.
- `l = a * b // g` : 최소공배수를 구한다.
  - `//` 는 **정수 나눗셈** 연산자이다. 소수점 이하를 버리고 정수만 반환한다.
  - `a * b`를 `g`로 나누면 항상 정수가 나오므로 `//`를 사용해도 정확하다.

```python
print(g)
print(l)
```
- 첫째 줄에 최대공약수 `g`를 출력한다.
- 둘째 줄에 최소공배수 `l`를 출력한다.

## 외울 것
> **"유클리드 호제법"은 `a, b = b, a % b` 반복으로 최대공약수를 구하고, "최소공배수"는 `(a * b) // GCD`로 구한다.**
