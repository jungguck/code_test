## 문제
좌표 평면에서 한 점 $(x, y)$가 주어진다.
이 점은 직사각형 내부에 위치해 있으며, 직사각형의 왼쪽 아래 꼭짓점은 $(0, 0)$, 오른쪽 위 꼭짓점은 $(w, h)$이다.
직사각형의 네 변(경계선) 중 가장 가까운 변까지의 거리를 구하라.

## 입력
- 첫째 줄: $x, y, w, h$ (공백으로 구분된 정수 4개)

## 출력
- 첫째 줄: 직사각형의 경계선까지의 최단 거리

## 예제
```
입력          출력
1 1 5 5       1
```
점 $(1, 1)$에서 왼쪽 변($x=0$)까지 거리는 $1$, 아래 변($y=0$)까지 거리는 $1$,
오른쪽 변($x=5$)까지 거리는 $4$, 위 변($y=5$)까지 거리는 $4$이다.
이 중 최솟값인 $1$을 출력한다.

## 풀이 아이디어
**핵심 질문: "점 $(x, y)$에서 네 방향(좌, 우, 상, 하)으로 나가는 거리 중 가장 짧은 것은?"**

직사각형은 좌표축에 평행하므로, 점 $(x, y)$에서 각 변까지의 거리는 단순히 좌표 차이의 절댓값으로 구할 수 있다.
1. **왼쪽 변** ($x=0$)까지의 거리: $x - 0 = x$
2. **아래 변** ($y=0$)까지의 거리: $y - 0 = y$
3. **오른쪽 변** ($x=w$)까지의 거리: $w - x$
4. **위 변** ($y=h$)까지의 거리: $h - y$

이 네 가지 값 중 가장 작은 값을 찾으면 된다.

```
      (0,h) ____________ (w,h)
           |              |
           |      (x,y)   |
           |              |
      (0,0) ____________ (w,0)

  거리 계산:
  - 왼쪽: x
  - 아래: y
  - 오른쪽: w - x
  - 위: h - y
```

## 코드 따라가기
```python
x, y, w, h = map(int, input().split())
```
- `input().split()`: 입력받은 문자열을 공백 기준으로 잘라서 리스트로 만든다. (예: `"1 1 5 5"` -> `['1', '1', '5', '5']`)
- `map(int, ...)`: 리스트 안의 모든 문자열을 정수(`int`)로 변환한다.
- `x, y, w, h = ...`: 변환된 네 개의 정수를 각각 변수 `x`, `y`, `w`, `h`에 대입한다. (언패킹)

```python
print(min(x, y, w - x, h - y))
```
- `w - x`: 오른쪽 변까지의 거리
- `h - y`: 위 변까지의 거리
- `min(...)`: 괄호 안에 들어온 네 가지 값(`x`, `y`, `w-x`, `h-y`) 중 가장 작은 값을 반환한다.
- `print(...)`: 구한 최단 거리를 출력한다.

## 외울 것
> **"직사각형 경계까지 최단 거리" → 좌/우/상/하 네 방향 거리(`x`, `y`, `w-x`, `h-y`)를 구해 `min()`으로 비교.**
