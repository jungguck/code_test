## 문제
세 개의 자연수 A, B, C가 주어질 때, A × B × C의 곱을 구한 후, 그 결과 값에 0부터 9까지의 각 숫자가 몇 번씩 등장하는지 구하는 문제이다.

## 입력
- 첫째 줄: 자연수 A
- 둘째 줄: 자연수 B
- 셋째 줄: 자연수 C
- (A, B, C는 모두 100 이상 1,000 미만의 자연수)

## 출력
- 0이 몇 번 쓰였는지
- 1이 몇 번 쓰였는지
- ...
- 9가 몇 번 쓰였는지
(총 10줄에 걸쳐, 0부터 9까지 순서대로 한 줄에 하나씩 출력)

## 예제
```
입력          출력
150           3
266           1
427           0
              2
              0
              0
              0
              2
              0
              0
```
`150 * 266 * 427 = 17037300` 이므로,
0은 3번, 1은 1번, 2는 0번, 3은 2번, 4는 0번, 5는 0번, 6은 0번, 7은 2번, 8은 0번, 9는 0번 등장합니다.

## 풀이 아이디어
**핵심 질문: "곱한 결과를 문자열로 바꾸면, 특정 숫자가 몇 개 있는지 쉽게 셀 수 있을까?"**

1.  세 수를 곱해서 하나의 큰 숫자 `d`를 만든다.
2.  이 숫자 `d`를 **문자열**로 변환한다. (예: `17037300` -> `"17037300"`)
3.  0부터 9까지의 숫자를 하나씩 꺼내며, 이 문자열 안에 그 숫자가 몇 번 등장하는지 세면 된다.
    -   `str.count()` 함수를 사용하면 특정 문자가 몇 번 있는지 바로 알려준다.

## 코드 따라가기
```python
a = int(input())
b = int(input())
c = int(input())
```
첫째 줄부터 셋째 줄까지 입력을 받아 각각 정수 `a`, `b`, `c`에 저장한다.

```python
d = a * b * c
```
세 수를 곱해서 결과값 `d`를 구한다.

```python
for i in range(10):
    print(str(d).count(str(i)))
```
이 부분이 핵심이다.
1.  `range(10)`: 0, 1, 2, ..., 9까지의 숫자를 순서대로 `i`에 대입한다.
2.  `str(d)`: 정수 `d`를 문자열로 변환한다. (예: `17037300` -> `"17037300"`)
    -   *왜?* 숫자 자체는 '0이 몇 개 있는지'를 세는 함수가 없기 때문에, 문자열로 바꿔야 `count()`를 쓸 수 있다.
3.  `str(i)`: 현재 검사하려는 숫자 `i` (예: 0)도 문자열로 변환한다. (예: `0` -> `"0"`)
    -   *왜?* `count()`는 문자열 안에서 **문자열**을 찾는다. 정수 `0`을 찾게 하면 안 되므로 `"0"`으로 바꿔야 한다.
4.  `str(d).count(str(i))`: 문자열 `d` 안에 문자열 `i`가 몇 번 등장하는지 세어 출력한다.

## 외울 것
> **"숫자의 자릿수별 빈도"를 구할 때는 정수를 문자열로 변환(`str()`)하고, `count()` 함수를 활용하자.**
