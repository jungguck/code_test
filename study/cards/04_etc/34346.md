## 문제
크기 N×N의 격자가 있다. 정확히 한 행만 선택하여 그 행에서 원하는 만큼의 칸을 색칠할 수 있다.
양쪽 대각선(주대각선과 부대각선) 모두에 색칠된 칸이 존재하도록 만들고자 한다.
칠해야 하는 칸의 최소 개수를 구하여라.

## 입력
- 첫째 줄: 양의 정수 N (2 ≤ N ≤ 10)

## 출력
- 조건을 만족하기 위해 칠해야 하는 칸의 최소 개수

## 예제
```
입력   출력
2      2
```
N=2일 때, 주대각선은 (1,1), (2,2)이고 부대각선은 (1,2), (2,1)이다.
한 행만 고를 수 있으므로, 1행을 고르면 (1,1)과 (1,2)를 모두 칠해야 하므로 2개.
2행을 고르면 (2,2)과 (2,1)를 모두 칠해야 하므로 2개.
따라서 답은 2이다.

## 풀이 아이디어
**핵심 질문: "한 행 안에서 주대각선 칸과 부대각선 칸이 겹치는가?"**

1. **주대각선**: (1,1), (2,2), ..., (N,N)
2. **부대각선**: (1,N), (2,N-1), ..., (N,1)

우리는 **한 행(i행)** 을 고르고, 그 행에 있는 주대각선 칸과 부대각선 칸을 모두 색칠해야 합니다.
- 만약 i행에서 주대각선 칸과 부대각선 칸이 **같은 위치**라면, 그 칸 하나만 색칠하면 두 조건을 동시에 만족하므로 **1개**면 됩니다.
- 만약 i행에서 주대각선 칸과 부대각선 칸이 **다른 위치**라면, 두 칸을 모두 색칠해야 하므로 **2개**가 필요합니다.

**언제 같은 위치인가?**
i행의 주대각선 칸은 (i, i)입니다.
i행의 부대각선 칸은 (i, N-i+1)입니다.
두 칸이 같으려면 열 번호가 같아야 하므로:
`i = N - i + 1`
`2i = N + 1`
`i = (N + 1) / 2`

이 방정식이 성립하려면 **N+1이 짝수**, 즉 **N이 홀수**여야 합니다.
- **N이 홀수**일 때: 중앙 행(i = (N+1)/2)에서 두 대각선이 교차합니다. 이 행을 고르면 **1개**만 칠하면 됩니다.
- **N이 짝수**일 때: 어떤 행에서도 두 대각선이 교차하지 않습니다. 어떤 행을 고르든 두 칸을 모두 칠해야 하므로 **2개**가 필요합니다.

따라서 답은 N의 홀짝성에 따라 결정됩니다.

## 코드 따라가기
```python
n = int(input())
```
첫째 줄에서 입력받은 N을 정수로 변환하여 변수 `n`에 저장합니다.

```python
print(1 if n % 2 == 1 else 2)
```
이 줄은 **삼항 연산자(조건식)** 를 사용한 한 줄 코드입니다.
- `n % 2 == 1`: N을 2로 나눈 나머지가 1인지 확인합니다. 즉, **N이 홀수인지** 확인하는 식입니다.
- `1 if ... else 2`: 
  - 만약 `n % 2 == 1`이 참(True)이라면, 즉 N이 홀수라면 `1`을 출력합니다.
  - 만약 `n % 2 == 1`이 거짓(False)이라면, 즉 N이 짝수라면 `2`를 출력합니다.

**왜 이렇게 푸는가?**
위에서 분석한 대로, N이 홀수이면 대각선이 교차하는 행이 존재하므로 최소 1칸만 칠하면 되고, N이 짝수이면 교차하는 행이 없으므로 최소 2칸을 칠해야 합니다. 따라서 N의 홀짝성만 확인하면 답을 알 수 있습니다.

## 외울 것
> **"한 행만 선택하여 두 조건(주대각선, 부대각선)을 만족" → 두 대각선이 교차하는지 확인 → N이 홀수이면 교차(1칸), 짝수이면 미교차(2칸)."**
