## 문제
선반 위에 N개의 트로피가 왼쪽부터 차례대로 놓여 있다.
트로피는 앞(왼쪽)에 있는 트로피보다 높이가 **크거나 같지 않으면** 가려져서 보이지 않는다.
즉, 왼쪽에서 봤을 때 보이는 트로피는 "지금까지 본 트로피 중 가장 높은 것보다 높은" 트로피만 해당된다.
1. 왼쪽에서 봤을 때 보이는 트로피의 개수
2. 오른쪽에서 봤을 때 보이는 트로피의 개수
를 각각 구하라.

## 입력
- 첫째 줄: 트로피의 개수 N (1 ≤ N ≤ 50)
- 둘째 줄부터 N개의 줄: 왼쪽의 트로피부터 차례대로 높이가 주어진다. (100보다 작거나 같은 자연수)

## 출력
- 첫째 줄: 왼쪽에서 봤을 때 보이는 트로피의 개수
- 둘째 줄: 오른쪽에서 봤을 때 보이는 트로피의 개수

## 예제
```
입력          출력
5             3
1             2
2
3
4
5
```
왼쪽에서 보면 1, 2, 3, 4, 5 모두 이전 것보다 높으므로 5개가 보인다? 아니다.
예제 입력이 1,2,3,4,5라면 왼쪽에서 5개, 오른쪽에서 1개(5)가 보인다.
하지만 문제의 논리상 "앞의 트로피가 뒤에 있는 트로피를 가린다"는 의미는,
**왼쪽에서 오른쪽으로 스캔할 때, 현재 높이가 지금까지의 최대 높이보다 크면 보이는 것**이다.

*수정된 예시 설명 (문제 지문 기준):*
만약 높이가 `1 2 3 4 5`라면:
- 왼쪽에서: 1(보임), 2(1보다 큼, 보임), 3(2보다 큼, 보임), 4(3보다 큼, 보임), 5(4보다 큼, 보임) -> 5개
- 오른쪽에서: 5(보임), 4(5보다 작음, 가림), 3(5보다 작음, 가림), 2(5보다 작음, 가림), 1(5보다 작음, 가림) -> 1개

(참고: BOJ 1668의 실제 예제는 다음과 같다)
```
입력          출력
5             3
1             2
2
3
4
5
```
*실제 BOJ 예제는 보통 `1 2 3 4 5`가 아니라 다른 값일 수 있으나, 코드 로직에 따라 설명한다.*
가장 흔한 예시:
입력:
5
1
2
3
4
5
출력:
5
1

또 다른 예시:
입력:
5
5
4

2
1
출력:
1
5

## 풀이 아이디어
**핵심 질문: "지금 보고 있는 트로피가, 내 왼쪽(또는 오른쪽)에 있는 모든 트로피보다 높은가?"**

트로피가 가려지는 조건은 "앞에 있는 트로피가 뒤에 있는 트로피보다 높은 경우"이다.
따라서 왼쪽에서부터 하나씩 살펴볼 때, **지금까지 본 트로피 중 가장 높은 높이(`max_h`)**를 기억해 두면 된다.
현재 트로피의 높이가 `max_h`보다 크다면, 이 트로피는 왼쪽의 어떤 트로피에도 가려지지 않으므로 **보이는 트로피**다.
이때 `max_h`를 현재 높이로 갱신하고, 카운트를 1증가시킨다.

오른쪽에서 보는 경우는 단순히 트로피 배열을 **뒤집어서** 같은 로직을 적용하면 된다.
리스트를 뒤집으면, 원래 오른쪽 끝이 왼쪽 끝에 오므로, 왼쪽에서 보는 로직을 그대로 재사용할 수 있다.

```
왼쪽에서 보기:
[1, 2, 3, 4, 5]
max_h = 0
1 > 0? O -> count=1, max_h=1
2 > 1? O -> count=2, max_h=2
3 > 2? O -> count=3, max_h=3
4 > 3? O -> count=4, max_h=4
5 > 4? O -> count=5, max_h=5
결과: 5

오른쪽에서 보기 (리스트 뒤집기):
[5, 4, 3, 2, 1]
max_h = 0
5 > 0? O -> count=1, max_h=5
4 > 5? X
3 > 5? X
2 > 5? X
1 > 5? X
결과: 1
```

## 코드 따라가기
```python
n = int(input())
trophies = []
for _ in range(n):
    trophies.append(int(input()))
```
1. **입력 처리**: N을 읽고, N번 반복하여 트로피 높이를 `trophies` 리스트에 저장한다.
   `for _ in range(n)`는 N번 반복하되, 반복 변수를 사용하지 않을 때 `_`를 쓰는 관례다.

```python
def count_visible(lst):
    count = 0
    max_h = 0
    for h in lst:
        if h > max_h:
            count += 1
            max_h = h
    return count
```
2. **핵심 로직 함수**: `count_visible` 함수를 정의한다.
   - `count`: 보이는 트로피 개수를 세는 변수 (0으로 초기화)
   - `max_h`: 지금까지 본 트로피 중 가장 높은 높이 (0으로 초기화. 트로피 높이는 자연수이므로 0보다 클 수밖에 없음)
   - `for h in lst`: 리스트의 각 높이 `h`를 순회한다.
   - `if h > max_h`: 현재 높이가 지금까지의 최대 높이보다 **크면** (같으면 가려지므로 `>`만 사용)
     - `count += 1`: 보이는 트로피이므로 개수 증가
     - `max_h = h`: 최대 높이를 현재 높이로 갱신
   - `return count`: 최종적으로 보이는 개수를 반환한다.

```python
print(count_visible(trophies))         # 왼쪽
print(count_visible(trophies[::-1]))   # 오른쪽 (리스트 뒤집기)
```
3. **출력**:
   - `count_visible(trophies)`: 원래 순서(왼쪽부터)로 함수를 호출하여 왼쪽에서 보이는 개수를 출력한다.
   - `count_visible(trophies[::-1])`: `trophies[::-1]`은 리스트를 **뒤집은 새로운 리스트**를 만든다.
     - `[::-1]`은 슬라이싱 문법으로, 시작:끝:간격 형식이다. 간격이 `-1`이면 뒤에서 앞으로 순회한다.
     - 뒤집힌 리스트를 `count_visible`에 넣으면, 오른쪽에서 왼쪽으로 보는 것과 동일한 효과가 나온다.
     - 이렇게 하면 함수를 두 번 만들지 않고 한 번만 정의해도 된다.

## 외울 것
> **"앞에서 가린다"는 문제는 '지금까지의 최대값'을 추적하면 된다.**
> **왼쪽/오른쪽 방향을 바꾸고 싶으면 리스트를 `[::-1]`로 뒤집어서 같은 로직을 재사용하자.**
