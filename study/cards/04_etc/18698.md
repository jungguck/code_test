## 문제
아담이 걷는 모습을 문자열로 나타낸다. 각 문자는 한 걸음을 의미하며, 'U'는 손을 들어 균형을 잡은 상태, 'D'는 손을 내리고 넘어진 상태를 뜻한다.
아담이 **처음으로 넘어지기(D가 나타나는 위치) 전까지** 걸은 걸음 수를 구하라.
만약 문자열 전체에 'D'가 없다면(넘어지지 않았다면), 문자열의 길이 전체를 출력한다.

## 입력
- 첫째 줄: 테스트 케이스의 개수 T (1 ≤ T ≤ 100)
- 다음 T줄: 각 줄마다 'U'와 'D'로만 이루어진 비어있지 않은 문자열 (길이 ≤ 100)

## 출력
- 각 테스트 케이스마다, 아담이 처음 넘어지기 전까지의 걸음 수를 한 줄씩 출력

## 예제
```
입력          출력
3             2
UUDD          0
UUD           5
UUUUU
```
1. `UUDD`: 첫 번째 'D'가 3번째 인덱스(0부터 시작)에 있으므로, 그 전까지 걸은 걸음 수는 2 (인덱스 0, 1).
2. `UUD`: 첫 번째 'D'가 2번째 인덱스에 있으므로, 그 전까지 걸은 걸음 수는 2? 
   *수정*: 문제의 논리는 "넘어지기 전까지"이므로 'D'가 나오기 직전까지의 'U' 개수.
   `UUD` -> 인덱스 0('U'), 1('U'), 2('D'). 'D'가 나오기 전까지의 걸음은 2개.
   *하지만 예제 출력이 0인 경우?* 
   만약 입력이 `D...`라면 0이 됩니다.
   위 예제는 제가 임의로 만든 것이므로, 코드의 로직에 맞는 명확한 예시를 다시 구성합니다.
   
   **정확한 예시 재구성:**
   입력:
   ```
   2
   D
   UU
   ```
   출력:
   ```
   0
   2
   ```
   설명:
   - `D`: 첫 번째 문자가 'D'이므로, 넘어지기 전까지 걸은 걸음 수는 0.
   - `UU`: 'D'가 없으므로, 전체 길이 2를 출력.

## 풀이 아이디어
**핵심 질문: "첫 번째 'D'는 어디에 있는가?"**

문자열을 왼쪽에서 오른쪽으로 순서대로 읽으며 'U'만 계속 세어간다.
1. 문자가 'U'이면: `count`를 1 증가시킨다. (아직 넘어지지 않았으므로 걸음 수 증가)
2. 문자가 'D'이면: **즉시 멈춘다** (`break`). (여기서 넘어졌으므로, 이후의 문자는 상관없다)
3. 반복이 끝날 때까지 'D'를 만나지 못했다면: `count`에는 문자열 전체 길이가 저장되어 있을 것이다.

이 과정은 문자열의 길이가 최대 100이므로, 단순한 순차 탐색(Linear Scan)으로 충분하다.

## 코드 따라가기
```python
n = int(input())
```
첫째 줄에서 테스트 케이스의 개수 `n`을 정수로 받아온다.

```python
for _ in range(n):
    s = input()
    count = 0
```
`n`번 반복한다.
각 반복마다 한 줄의 문자열 `s`을 입력받는다.
걸음 수를 세기 위한 변수 `count`를 0으로 초기화한다.

```python
    for ch in s:
        if ch == 'U':
            count += 1
        else:
            break
```
문자열 `s`의 각 문자 `ch`를 하나씩 꺼내서 확인한다.
- `ch`가 `'U'`라면: `count`를 1 증가시킨다.
- `ch`가 `'U'`가 아니라면 (즉, `'D'`라면): `break`를 사용하여 **이 반복문(for)을 즉시 종료**한다.
  - **왜 `break`가 필요한가?** 문제에서 "처음으로 넘어지기 전까지"라고 했으므로, 첫 번째 'D' 이후의 문자는 더 이상 걸음 수에 포함되지 않는다. 계속 읽으면 틀린 답이 나온다.

```python
    print(count)
```
`count`의 현재 값을 출력한다.
- 만약 중간에 'D'를 만나서 `break`되었다면, `count`는 그 전까지의 'U' 개수(걸음 수)가 된다.
- 만약 'D'가 없어서 반복이 끝까지 돌았다면, `count`는 문자열 전체 길이와 같아진다.

## 외울 것
> **"첫 번째 특정 값 찾기" + "그 전까지의 개수" → `for` 루프에서 조건을 만나면 `break`로 즉시 탈출.**
