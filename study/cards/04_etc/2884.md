## 문제
현재 설정된 알람 시간(H시 M분)을 45분 앞당긴 시간을 구하는 문제이다.
1. 주어진 시간에서 45분을 뺀다.
2. 만약 분(M)이 45보다 작으면, 시(H)를 1시간 줄이고 분(M)에 15를 더한다. (60분 단위 이월 처리)
3. 만약 시(H)가 0이고 분(M)이 45보다 작으면, 시(H)는 23으로 바꾼다. (24시간제 롤오버)

## 입력
- 첫째 줄: 두 정수 H와 M (0 ≤ H ≤ 23, 0 ≤ M ≤ 59)

## 출력
- 45분 앞당긴 알람 시간 (H시 M분 형식, 공백으로 구분)

## 예제
```
입력          출력
12 30         11 45
```
12시 30분에서 45분을 빼면 11시 45분이 된다.
(30 < 45 이므로 시는 11로 줄고, 분은 30+15=45가 됨)

## 풀이 아이디어
**핵심 질문: "분을 45만큼 뺐을 때, 음수가 되면 어떻게 해야 하나?"**

시간 계산은 분(M)이 0~59 범위를 벗어나면 시(H)에 영향을 미친다.
1. **분(M) >= 45 인 경우**: 단순히 `M - 45` 하면 된다. 시(H)는 그대로.
2. **분(M) < 45 인 경우**: 
   - 분(M)은 60을 더해서 45를 빼는 것과 같다. 즉, `M + 60 - 45 = M + 15`.
   - 대신 시(H)는 1시간을 빼야 한다. (`H - 1`)
   - 만약 `H - 1`이 음수가 되면(즉, 원래 H가 0이었던 경우), 24시간제이므로 23시로 돌아간다.

```
경우 1: M >= 45
  H' = H
  M' = M - 45

경우 2: M < 45
  H' = H - 1  (만약 H-1 < 0 이면 23)
  M' = M + 15
```

## 코드 따라가기
```python
a, b = map(int, input().split())
```
- `input().split()`: 입력받은 문자열을 공백 기준으로 잘라서 리스트로 만든다. 예: `"12 30"` -> `["12", "30"]`
- `map(int, ...)`: 리스트 안의 각 요소를 정수(int)로 변환한다.
- `a, b = ...`: 변환된 두 개의 정수를 변수 `a`(시)와 `b`(분)에 각각 대입한다.

```python
if b >= 45:
    b -= 45
else:
    b += 15
    a -= 1
    if a < 0:
        a = 23
```
- **`if b >= 45:`**: 분이 45 이상이면, 분에서 45를 바로 뺀다. (`b -= 45` 는 `b = b - 45` 의 줄임)
- **`else:`**: 분이 45 미만이면,
    1. `b += 15`: 분에 15를 더한다. (60 - 45 = 15 이므로, 1시간을 빌려와서 45분을 빼는 것과 동일)
    2. `a -= 1`: 시에서 1을 뺀다. (분에서 1시간을 빌렸으므로)
    3. `if a < 0:`: 만약 시가 0이었는데 1을 빼서 -1이 되었다면, 24시간제이므로 23시로 설정한다.

```python
print(a, b)
```
- 최종적으로 계산된 시(`a`)와 분(`b`)을 공백으로 구분하여 출력한다.

## 외울 것
> **"시간에서 N분 빼기" → 분이 N보다 작으면 시를 1 줄이고, 분에 (60-N)을 더한다. 시가 음수가 되면 23으로 롤오버.**
