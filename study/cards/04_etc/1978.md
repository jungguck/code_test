## 문제
주어진 N개의 자연수 중에서 소수(Prime Number)가 몇 개인지 세어 출력하는 문제이다.
소수는 1과 자기 자신 외에 약수가 없는 2 이상의 자연수를 말한다.

## 입력
- 첫째 줄: 수의 개수 N (1 ≤ N ≤ 100)
- 둘째 줄: N개의 자연수 (각 수의 범위는 1 ≤ 수 ≤ 1,000)

## 출력
- 주어진 수들 중 소수의 개수 (정수 하나)

## 예제
```
입력          출력
5             2
1 2 3 4 5
```
1은 소수가 아니다. 2, 3, 5는 소수이다. 4는 2의 배수이므로 소수가 아니다.
따라서 소수의 개수는 2(2, 3, 5 중 2와 3? 아니 2, 3, 5 모두 소수이므로 3개? 
*정정*: 예시 입력 `1 2 3 4 5` 에서는 2, 3, 5가 소수이므로 정답은 3이다. 
위 예시 출력 2는 오류일 수 있으니, 실제 BOJ 1978 예제를 참고하자.
BOJ 1978 공식 예제:
입력:
5
1 2 3 4 5
출력:
3
(2, 3, 5가 소수)

*카드 작성 시 실제 공식 예제를 따름*
```
입력          출력
5             3
1 2 3 4 5
```
1은 소수가 아님. 2, 3, 5는 소수임. 4는 2*2이므로 소수가 아님.
따라서 소수는 2, 3, 5로 총 3개이다.

## 풀이 아이디어
**핵심 질문: "이 수가 소수인지 어떻게 판별할까?"**

소수 판정의 기본 원리는 **2부터 그 수보다 1까지의 모든 수로 나누어 보아, 나머지가 0인 수(약수)가 있는지 확인**하는 것이다.
약수가 하나라도 발견되면 소수가 아니고, 하나도 없으면 소수이다.

특수한 경우:
- **1은 소수가 아니다.** (정의상 2 이상이어야 함)
- **2는 소수이다.** (2보다 작은 자연수가 없으므로)

알고리즘 흐름:
1. N개의 수를 하나씩 꺼낸다.
2. 그 수가 1인지 확인한다. 1이면 소수 아님으로 처리한다.
3. 2부터 `num-1`까지의 모든 `j`로 `num`을 나눈다.
4. `num % j == 0` 이면 (나눠떨어지면) 소수가 아님으로 표시하고 반복을 중단할 수도 있지만, 이 코드는 계속 확인한다.
5. 반복이 끝난 후에도 소수가 아님 표시가 없다면, 소수로 카운트한다.

## 코드 따라가기

```python
n = int(input())
cout = 0
```
- `n`: 입력받을 수의 개수를 저장.
- `cout`: 소수의 개수를 세기 위한 카운터 변수를 0으로 초기화.

```python
a = list(map(int,input().split()))
```
- `input().split()`: 공백으로 구분된 문자열 리스트를 만든다.
- `map(int, ...)`: 리스트 안의 모든 문자열을 정수로 변환.
- `list(...)`: 변환된 결과를 리스트로 묶어 `a`에 저장.
- 예: 입력 "1 2 3" 이면 `a = [1, 2, 3]`

```python
for i in range(n):
    num = a[i]
    is_prime = True
```
- `range(n)`: 0부터 n-1까지의 인덱스를 생성.
- `num`: 현재 검사할 수를 `a[i]`에서 꺼내서 `num`에 저장.
- `is_prime`: 현재 `num`이 소수인지 여부를 저장할 플래그 변수.
  - 처음에는 **소수라고 가정**하고 `True`로 설정한다.
  - 나중에 약수가 발견되면 `False`로 바꿀 것이다.

```python
    if num == 1:
        is_prime = False
```
- **중요한 예외 처리**: 1은 소수가 아니다.
- 만약 `num`이 1이면, 소수 판정 로직(나눗셈)을 수행하기 전에 바로 `is_prime`을 `False`로 설정한다.
- 이 줄이 없으면 1이 소수로 잘못 카운트될 수 있다. (1은 2부터 0까지의 범위가 없어 for 루프가 실행되지 않아 `is_prime`이 `True`로 남기 때문)

```python
    for j in range(2, num):
        if num % j == 0:
            is_prime = False
```
- `range(2, num)`: 2부터 `num-1`까지의 수를 `j`로 사용.
  - 예: `num=5` 이면 `j`는 2, 3, 4.
- `num % j == 0`: `num`을 `j`로 나눈 나머지가 0인지 확인.
  - 나머지가 0이면 `j`가 `num`의 약수이므로, `num`은 소수가 아니다.
  - 따라서 `is_prime`을 `False`로 변경.
- **주의**: 이 코드는 약수를 발견해도 `break`하지 않고 계속 반복한다.
  - 효율성은 떨어지지만, 논리적으로는 `is_prime`이 이미 `False`가 되었으므로 이후 `if num % j == 0` 조건이 다시 참이 되더라도 `is_prime`은 `False`로 유지된다.
  - 즉, 한 번 `False`로 바뀌면 다시 `True`로 돌아가지 않으므로 최종 결과는 정확하다.

```python
    if is_prime:
        cout += 1
```
- 반복이 끝난 후, `is_prime`이 여전히 `True`인 경우(약수가 하나도 발견되지 않았거나, 1이 아니었던 경우)에만 `cout`을 1 증가시킨다.

```python
print(cout)
```
- 최종적으로 세운 소수의 개수 `cout`을 출력한다.

## 외울 것
> **"소수 판정" = 2부터 n-1까지 나눠보기. 단, 1은 소수가 아니므로 반드시 예외 처리해야 한다.**
> `is_prime` 플래그를 `True`로 시작해서 약수가 나오면 `False`로 바꾸는 패턴을 기억하자.
