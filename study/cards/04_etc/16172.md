## 문제
교과서 문자열 `S`와 키워드 문자열 `K`가 주어진다.
`S`에서 모든 숫자(0~9)를 제거한 후, 그 결과에 `K`가 부분문자열로 포함되어 있는지 확인한다.
- 포함되면 `1`을 출력한다.
- 포함되지 않으면 `0`을 출력한다.

## 입력
- 첫째 줄: 알파벳 소문자, 대문자, 숫자로 이루어진 문자열 `S` (1 ≤ |S| ≤ 200,000)
- 둘째 줄: 알파벳 소문자, 대문자로만 이루어진 키워드 문자열 `K` (1 ≤ |K| ≤ 200,000)

## 출력
- 키워드가 존재하면 `1`, 존재하지 않으면 `0`

## 예제
```
입력          출력
Hello123World 1
World
```
`S`에서 숫자 `1`, `2`, `3`을 제거하면 `HelloWorld`가 된다.
`K`인 `World`는 `HelloWorld` 안에 있으므로 `1`이 출력된다.

## 풀이 아이디어
**핵심 질문: "숫자가 섞여 있어도 키워드를 찾을 수 있는가?"**

1. **숫자 제거**: 문제의 조건에 따라 `S`에 포함된 모든 숫자를 삭제해야 한다.
   - `S`의 길이가 최대 200,000이고, 숫자는 0~9까지 10개뿐이므로,
   - 0부터 9까지의 숫자 문자열을 하나씩 찾아서 빈 문자열(`''`)로 치환(replace)하는 것이 가장 직관적이고 효율적인 방법이다.
2. **부분문자열 확인**: 숫자가 제거된 `S`에서 `K`가 연속으로 나타나는지 확인한다.
   - 파이썬에서는 `in` 연산자를 사용하면 부분문자열 존재 여부를 빠르게 확인할 수 있다.

```
원본 S:   H e l l o 1 2 3 W o r l d
숫자 제거: H e l l o       W o r l d  -> "HelloWorld"
키워드 K: W o r l d
결과:     "World" in "HelloWorld" ? -> True (1)
```

## 코드 따라가기

```python
S = input()
K = input()
```
- `input()`: 한 줄씩 문자열을 입력받는다.
- `S`: 교과서 내용 (숫자가 섞여 있을 수 있음)
- `K`: 찾고자 하는 키워드 (숫자 없음)

```python
for i in range(10):
    S = S.replace(str(i), '')
```
- `range(10)`: 0, 1, 2, ..., 9까지 순회한다.
- `str(i)`: 숫자 `i`를 문자열로 변환한다. (예: `i=1`이면 `'1'`)
- `S.replace(str(i), '')`: `S` 안에 있는 `str(i)`에 해당하는 모든 문자를 빈 문자열(`''`)로 바꾼다.
  - 즉, `S`에서 숫자 `i`를 모두 삭제한다.
  - 이 과정을 0~9까지 반복하면 `S`에서 모든 숫자가 제거된다.
  - **주의**: `replace`는 새로운 문자열을 반환하므로, `S = ...`로 다시 할당해줘야 `S`가 실제로 변한다.

```python
print(1 if K in S else 0)
```
- `K in S`: `S` 안에 `K`가 부분문자열로 포함되어 있는지 확인한다.
  - 포함되면 `True`, 아니면 `False`를 반환한다.
- `1 if ... else 0`: 파이썬의 **삼항 연산자** (조건식) 문법이다.
  - `조건식 if 참일_때_값 else 거짓일_때_값`
  - `K in S`가 `True`이면 `1`을, `False`이면 `0`을 출력한다.

## 외울 것
> **"특정 문자(숫자 등)를 모두 제거하고 부분문자열을 찾는다" → `for`문으로 대상 문자를 순회하며 `replace`로 빈 문자열(`''`)로 치환 → `in` 연산자로 포함 여부 확인.**
