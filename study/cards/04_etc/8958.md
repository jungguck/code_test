## 문제
"OOXXOXXOOO"와 같은 OX퀴즈 결과가 주어진다.
1. `O`는 문제를 맞은 것, `X`는 틀린 것이다.
2. `O`일 때의 점수는 **그 문제까지 연속된 O의 개수**이다. (예: `OOO`의 마지막 O는 3점)
3. `X`일 때의 점수는 0점이고, 연속 O 카운트가 초기화된다.
4. 전체 문자열의 점수 합을 구한다.

## 입력
- 첫째 줄: 테스트 케이스의 개수 N
- 다음 N줄: 각 테스트 케이스의 OX 문자열 (길이 0보다 크고 80보다 작은 문자열, `O`와 `X`로만 구성)

## 출력
- 각 테스트 케이스마다 계산된 점수를 한 줄씩 출력

## 예제
```
입력          출력
1             10
OOXXOXXOOO
```
`O(1) + O(2) + X(0) + X(0) + O(1) + X(0) + X(0) + O(1) + O(2) + O(3) = 10`

## 풀이 아이디어
**핵심 질문: "지금까지 연속해서 몇 개의 O를 맞았는가?"**

단순히 `O`의 개수를 세는 것이 아니라, **연속성**에 따라 점수가 달라진다.
- `O`를 만나면: 연속 카운트(`cout`)를 1 증가시키고, 그 값을 총점(`total`)에 더한다.
- `X`를 만나면: 연속 카운트(`cout`)를 0으로 초기화한다.

이 로직을 문자열의 각 문자에 대해 순서대로 적용하면 된다.

```
문자열: O O X X O X X O O O
cout:   1 2 0 0 1 0 0 1 2 3
total:  1 3 3 3 4 4 4 5 7 10
```

## 코드 따라가기
```python
n = int(input())
```
첫째 줄에서 테스트 케이스의 개수 `n`을 정수로 받아온다.

```python
for i in range(n):
    cout = 0
    total = 0
    a = input()
```
`n`번 반복한다.
각 반복 시작 시:
- `cout`: 현재 연속 O의 개수를 저장할 변수를 0으로 초기화.
- `total`: 현재 케이스의 총 점수를 저장할 변수를 0으로 초기화.
- `a`: 한 줄의 OX 문자열을 입력받는다.

```python
    for x in a:
        if x == 'O':
            cout += 1
            total += cout
        elif x == 'X':
            cout = 0
```
문자열 `a`의 각 문자 `x`를 하나씩 검사한다.
- `x`가 `'O'`라면:
    - `cout`을 1 증가시킨다. (연속 O가 하나 더 늘었으므로)
    - 증가한 `cout` 값을 `total`에 더한다. (이 O의 점수가 연속 O 개수이므로)
- `x`가 `'X'`라면:
    - `cout`을 0으로 초기화한다. (연속성이 끊겼으므로)

```python
    print(total)
```
한 케이스의 모든 문자를 처리한 후, 계산된 총점 `total`을 출력한다.

## 외울 것
> **"연속된 O의 개수가 점수" → `O`면 카운트 증가 후 점수 추가, `X`면 카운트 초기화.**
