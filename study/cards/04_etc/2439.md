## 문제
첫째 줄에는 별 1개, 둘째 줄에는 별 2개, N번째 줄에는 별 N개를 찍는 문제이다.
다만, 별은 **오른쪽을 기준으로 정렬**되어 있어야 한다.

## 입력
- 첫째 줄: N (1 ≤ N ≤ 100)

## 출력
- 첫째 줄부터 N번째 줄까지 차례대로 별을 출력한다.
- 각 줄의 앞부분은 공백으로 채우고, 뒷부분은 별(`*`)로 채운다.

## 예제
```
입력          출력
5             *
              **
              ***
              ****
              *****
```
N=5일 때, 1번째 줄은 공백 4개 + 별 1개, 2번째 줄은 공백 3개 + 별 2개, ..., 5번째 줄은 공백 0개 + 별 5개이다.

## 풀이 아이디어
**핵심 질문: "i번째 줄에 몇 개의 공백과 몇 개의 별이 필요한가?"**

N개의 줄을 출력할 때, i번째 줄(1부터 시작)의 구조는 다음과 같다:
- **공백의 개수**: `N - i`
- **별의 개수**: `i`

이 패턴을 이해하면, 각 줄은 `(공백 문자열) + (별 문자열)` 이라는 단순한 문자열 연결로 해결할 수 있다.

```
줄 번호(i) | 공백 개수(N-i) | 별 개수(i)
-----------|---------------|-----------
1          | 4             | 1
2          | 3             | 2
3          | 2             | 3
4          | 1             | 4
5          | 0             | 5
```

## 코드 따라가기
```python
n = int(input())
```
첫째 줄에서 입력받은 N을 정수로 변환하여 변수 `n`에 저장한다.

```python
for i in range(1, n+1):
```
`range(1, n+1)` 은 1부터 n까지의 정수를 순서대로 생성한다.
즉, `i` 는 1, 2, 3, ..., n 의 값을 차례로 가진다.
이 반복문은 총 n번 실행되어 n개의 줄을 출력한다.

```python
    print(" " * (n - i) + "*" * i)
```
이 줄이 핵심이다. 두 부분으로 나눌 수 있다:

1. `" " * (n - i)`
   - `" "` (공백 문자 하나)를 `n - i` 번 반복한다.
   - 예: n=5, i=1 이면 `" " * 4` → `"    "` (공백 4개)
   - 예: n=5, i=5 이면 `" " * 0` → `""` (빈 문자열)

2. `"*" * i`
   - `"*"` (별 문자 하나)를 `i` 번 반복한다.
   - 예: i=1 이면 `"*"`
   - 예: i=5 이면 `"*****"`

3. `+` 연산자
   - 앞의 공백 문자열과 뒤의 별 문자열을 연결한다.
   - 예: `"    " + "*"` → `"    *"`

`print()` 함수는 이 연결된 문자열을 한 줄로 출력한다.

## 외울 것
> **"오른쪽 정렬" = 앞쪽에 공백을 채운다. i번째 줄은 공백 (N-i)개 + 별 i개.**
> 문자열 반복은 `"문자" * 횟수` 로 표현한다.
