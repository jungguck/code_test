## 문제
10개의 수를 입력받아, 그중 **홀수만** 더한 값을 출력한다.

## 입력
- 첫째 줄: 테스트 케이스의 개수 T
- 다음 T줄: 각 줄에 10개의 수 (각 수는 0 이상 10000 이하의 정수)

## 출력
- 각 줄은 `#t` 로 시작하고, 공백 한 칸 뒤에 정답을 출력한다. (t는 1부터 시작하는 테스트 케이스 번호)

## 예제
```
입력                              출력
3                                 #1 200
3 17 1 39 8 41 2 32 99 2          #2 208
22 8 5 123 7 2 63 7 3 46          #3 121
6 63 2 3 58 76 21 33 8 1
```
1번 줄의 홀수: 3 + 17 + 1 + 39 + 41 + 99 = 200

## 풀이 아이디어
**핵심 질문: "이 수가 홀수인가?"** → `num % 2 == 1`

한 줄의 수를 하나씩 꺼내서, 홀수일 때만 합계에 더한다.
합계 변수는 **테스트 케이스마다 0으로 다시 시작**해야 한다.

## 코드 따라가기
```python
n = int(input())
```
첫째 줄의 테스트 케이스 개수 T를 정수로 받는다.

```python
for i in range(1, n + 1):
```
`i` 는 출력의 `#1`, `#2` … 에 그대로 쓸 번호다.
번호가 1부터 시작하므로 `range(n)` 이 아니라 `range(1, n + 1)` 을 쓴다. (`range(1, 4)` → 1, 2, 3)

```python
    numbers = list(map(int, input().split()))
    odd_sum = 0
```
- `input().split()` : 한 줄을 공백 기준으로 잘라 문자열 목록으로 만든다 → `['3', '17', '1', ...]`
- `map(int, ...)` : 그 문자열 하나하나에 `int` 를 적용한다
- `list(...)` : 결과를 리스트로 만든다 → `[3, 17, 1, ...]`
- `odd_sum = 0` : **반복문 안에서** 0으로 만든다. 밖에 두면 앞 케이스의 합이 다음 케이스에 계속 쌓인다.

```python
    for num in numbers:
        if num % 2 == 1:
            odd_sum += num
```
`%` 는 나머지 연산이다. 2로 나눈 나머지가 1이면 홀수, 0이면 짝수.
홀수일 때만 `odd_sum` 에 더한다. (`odd_sum += num` 은 `odd_sum = odd_sum + num` 과 같다)

```python
    print(f"#{i} {odd_sum}")
```
f-문자열: 따옴표 앞에 `f` 를 붙이면 `{ }` 안의 변수가 값으로 바뀐다.
`i = 1, odd_sum = 200` 이면 → `#1 200`

## 이 코드의 버그
처음 풀 때 나왔던 실수 두 개. 둘 다 **변수 이름 오타**다.

| 틀린 코드 | 무슨 일이 생기나 |
|---|---|
| `odd_num += num` | `odd_num` 은 만든 적 없는 변수 → `NameError` |
| `print(f"#{i} {iodd_num}")` | 역시 없는 변수 → `NameError` |

변수를 만든 줄(`odd_sum = 0`)과 쓰는 줄의 이름이 **글자 하나까지 같은지** 확인할 것.

## 외울 것
> **조건 누적합 = 합계를 0으로 시작 → `for` 로 하나씩 → `if` 조건 맞을 때만 `+=`.**
> **합계 초기화는 테스트 케이스 반복문 *안*에. SWEA 출력은 `print(f"#{i} {답}")`.**
