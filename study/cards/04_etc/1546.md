## 문제
세준이가 기말고사 점수를 조작해서 집에 가져가려고 한다.
조작 방법은 다음과 같다:
1. 자기 점수 중 최댓값을 M이라고 한다.
2. 모든 점수를 `점수 / M * 100` 으로 고친다.
3. 이렇게 고친 점수들의 평균을 구한다.

새로운 평균을 출력하시오.

## 입력
- 첫째 줄: 시험 본 과목의 개수 N (1 ≤ N ≤ 1000)
- 둘째 줄: 세준이의 현재 성적 N개 (100보다 작거나 같은 음이 아닌 정수, 적어도 하나는 0보다 크다)

## 출력
- 첫째 줄: 새로운 평균 (실제 정답과 출력값의 절대오차 또는 상대오차가 10^-2 이하이면 정답)

## 예제
```
입력          출력
3             71.428571
50 80 100
```
최댓값은 100이므로, 각 점수는 `50/100*100 = 50`, `80/100*100 = 80`, `100/100*100 = 100` 이 된다.
평균은 `(50 + 80 + 100) / 3 = 76.66...` 이 아니라, 문제의 예시처럼 `50/100*100 + 80/100*100 + 100/100*100` 의 합을 N으로 나눈 값이다.
(참고: 위 예시 출력값 71.428571은 다른 예시 입력에 해당할 수 있으나, 논리는 동일하다. 실제 BOJ 1546 예시는 `3\n50 80 100` -> `76.666667` 이다. 여기서는 코드 로직에 맞춰 설명한다.)

*수정된 예시 설명 (BOJ 공식 예시 기준)*:
입력:
```
3
50 80 100
```
출력:
```
76.666667
```
최댓값 M=100. 변환된 점수: 50, 80, 100. 평균: (50+80+100)/3 = 76.666...

## 풀이 아이디어
**핵심 질문: "점수를 어떻게 비율로 변환해서 평균을 구할까?"**

1. **최댓값 찾기**: 모든 점수 중 가장 큰 값(M)을 찾아야 한다. 이 값이 기준이 된다.
2. **점수 변환**: 각 점수 `s`를 `s / M * 100` 으로 변환한다.
   - 왜 `* 100` 인가? 문제에서 "점수/M*100" 으로 고친다고 했기 때문이다.
   - 예: M=70, s=50 이면 `50/70*100 ≈ 71.43`
3. **평균 계산**: 변환된 점수들의 합을 과목 수 N으로 나눈다.

```
원본 점수: [50, 80, 100]
최댓값 M: 100

변환 과정:
50 / 100 * 100 = 50.0
80 / 100 * 100 = 80.0
100 / 100 * 100 = 100.0

합: 50.0 + 80.0 + 100.0 = 230.0
평균: 230.0 / 3 = 76.666...
```

## 코드 따라가기

```python
n = int(input())
scores = list(map(int, input().split()))
```
- `n = int(input())`: 첫째 줄에서 과목 개수 N을 정수로 받는다.
- `scores = list(map(int, input().split()))`:
  - `input().split()`: 둘째 줄의 공백으로 구분된 문자열을 리스트로 쪼갠다. (예: `['50', '80', '100']`)
  - `map(int, ...)`: 이 리스트의 각 요소를 정수로 변환한다.
  - `list(...)`: map 객체를 리스트로 만들어 저장한다. (예: `[50, 80, 100]`)

```python
# 네가 하던 방식처럼 max 직접 찾기
max_val = scores[0]

for s in scores:
    if s > max_val:
        max_val = s
```
- `max_val = scores[0]`: 첫 번째 점수를 임시로 최댓값으로 설정한다.
- `for s in scores:`: 점수 리스트의 각 점수 `s`를 하나씩 꺼낸다.
- `if s > max_val:`: 현재 점수가 지금까지의 최댓값보다 크면,
- `max_val = s`: 최댓값을 현재 점수로 갱신한다.
- **왜 `max()` 함수를 안 썼나?** 문제 해결 과정에서 직접 비교하는 방식을 연습하기 위함이다. `max(scores)` 를 쓰면 한 줄로 끝난다.

```python
# 평균 계산 (네 공식 유지)
average = 0
for s in scores:
    average += (s / max_val) * 100

average = average / n

print(average)
```
- `average = 0`: 변환된 점수들의 합을 저장할 변수를 0으로 초기화한다.
- `for s in scores:`: 각 점수를 다시 꺼낸다.
- `average += (s / max_val) * 100`:
  - `s / max_val`: 현재 점수를 최댓값으로 나눈 비율을 구한다. (소수)
  - `* 100`: 문제의 공식에 따라 100을 곱한다.
  - `+=`: 이 값을 `average` 에 더한다.
- `average = average / n`: 합을 과목 수 N으로 나누어 평균을 구한다.
- `print(average)`: 결과를 출력한다. Python은 실수 출력을 자동으로 적절한 소수점 자리로 처리하므로, 오차 범위 내에서 정답이 된다.

## 외울 것
> **"비율 변환 후 평균" 문제 → 1) 최댓값 찾기, 2) 각 값/최댓값*100 해서 합산, 3) 합/개수로 평균.**
> `map(int, input().split())` 은 여러 개의 정수를 한 줄로 받을 때 필수 패턴이다.
