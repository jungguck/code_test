## 문제
다장조의 8개 음(c, d, e, f, g, a, b, C)을 숫자 1~8로 변환한 순서가 주어진다.
이 순서가 어떤 패턴을 따르는지 판별한다.
1. 1부터 8까지 차례대로 오르면 `ascending`
2. 8부터 1까지 차례대로 내리면 `descending`
3. 위 두 가지가 아니면 `mixed`

## 입력
- 첫째 줄: 공백으로 구분된 8개의 정수 (1~8까지의 숫자가 각각 한 번씩 등장)

## 출력
- 첫째 줄: `ascending`, `descending`, `mixed` 중 하나

## 예제
```
입력          출력
1 2 3 4 5 6 7 8   ascending
8 7 6 5 4 3 2 1   descending
1 2 3 4 5 6 8 7   mixed
```
첫 번째 예제는 1부터 8까지 연속으로 증가하므로 `ascending`이다.
세 번째 예제는 마지막에 8에서 7로 내려가므로 `mixed`가 된다.

## 풀이 아이디어
**핵심 질문: "인접한 두 숫자의 크기가 어떻게 변하는가?"**
8개의 숫자가 주어졌으므로, 앞뒤로 인접한 숫자 쌍(1번째와 2번째, 2번째와 3번째, ..., 7번째와 8번째)을 비교한다.
- 모든 쌍이 `앞 < 뒤` 이면 `ascending`
- 모든 쌍이 `앞 > 뒤` 이면 `descending`
- 그 외에는 `mixed`

코드의 전략은 **첫 번째 비교 결과**로 초기 방향을 정하고, 이후 비교에서 **방향과 반대되는 경우**가 나오면 `mixed`로 바꾸는 것이다.

## 코드 따라가기
```python
a = list(map(int, input().split()))
```
`input().split()`으로 입력받은 문자열을 공백 기준으로 잘라 리스트로 만들고, `map(int, ...)`으로 각 요소를 정수로 변환한 뒤 `list()`로 최종 리스트를 만든다.
`a`는 이제 `[1, 2, 3, 4, 5, 6, 7, 8]` 같은 형태의 정수 8개를 가진 리스트이다.

```python
if a[1] > a[0]:
    result = "ascending"
elif a[1] < a[0]:
    result = "descending"
```
첫 번째 숫자(`a[0]`)와 두 번째 숫자(`a[1]`)를 비교한다.
- `a[1] > a[0]` (예: 1, 2): 처음에는 올라가는 추세이므로 `result`를 `"ascending"`으로 초기화한다.
- `a[1] < a[0]` (예: 8, 7): 처음에는 내려가는 추세이므로 `result`를 `"descending"`으로 초기화한다.
(1~8까지의 숫자가 중복 없이 등장하므로 `a[1] == a[0]`인 경우는 없다.)

```python
for i in range(1, 8):
    if a[i] > a[i-1]:
        if result == "descending":  # 내려가다가 올라가면
            result = "mixed"
            break
    elif a[i] < a[i-1]:
        if result == "ascending":   # 올라가다가 내려가면
            result = "mixed"
            break
        result = "descending"  # ← 이게 빠져있었어요!
```
`range(1, 8)`은 1부터 7까지의 정수를 만든다. 즉, `i`는 1, 2, 3, 4, 5, 6, 7을 차례로 가진다.
이 반복문은 `a[i]`와 `a[i-1]`을 비교하며 전체 순서를 검사한다.

- `if a[i] > a[i-1]:`
  - 현재 숫자가 이전 숫자보다 크다 (올라감).
  - 만약 `result`가 `"descending"`이었다면, "내려가다가 올라갔다"는 뜻이므로 `result`를 `"mixed"`로 바꾸고 `break`로 반복문을 종료한다.
  - (참고: `result`가 `"ascending"`인 경우라면 계속 올라가는 것이므로 아무 일도 일어나지 않고 다음 `i`로 넘어간다.)

- `elif a[i] < a[i-1]:`
  - 현재 숫자가 이전 숫자보다 작다 (내려감).
  - 만약 `result`가 `"ascending"`이었다면, "올라가다가 내려갔다"는 뜻이므로 `result`를 `"mixed"`로 바꾸고 `break`로 반복문을 종료한다.
  - 만약 `result`가 `"descending"`이었다면, 계속 내려가는 것이므로 아무 일도 일어나지 않고 다음 `i`로 넘어간다.
  - **주의**: 코드 주석에 "← 이게 빠져있었어요!"라고 적혀 있지만, 실제 코드 로직을 보면 `result = "descending"`이라는 줄이 `elif` 블록 안에 존재한다.
    - 만약 이 줄이 없다면, `result`가 `"descending"`인 상태에서 계속 내려가는 경우(`a[i] < a[i-1]`)에 `result` 값이 유지되지 않고(초기값 그대로) 다음으로 넘어간다.
    - 하지만 이 문제에서는 `result`가 `"descending"`인 상태에서 `a[i] < a[i-1]`인 경우, `result`는 이미 `"descending"`이므로 `result = "descending"`을 실행해도 값이 변하지 않는다.
    - **실제로는 이 줄이 없어도 정답이 나온다.** 왜냐하면 `result`가 `"descending"`인 상태에서 `a[i] < a[i-1]`이면 `result`는 그대로 `"descending"`으로 유지되기 때문이다.
    - 그러나 코드의 의도는 "현재 방향이 내려감임을 확인하고 명시적으로 설정한다"는 것일 수 있다.
    - **중요**: 주석의 "← 이게 빠져있었어요!"는 **오해의 소지가 있는 주석**이다. 이 줄이 없어도 논리적으로 문제는 없다. 왜냐하면 `result`가 `"descending"`인 상태에서 `a[i] < a[i-1]`이면 `result`는 이미 `"descending"`이므로 `result = "descending"`을 실행해도 값이 변하지 않기 때문이다.
    - **하지만**, 만약 `result`가 초기화되지 않은 상태(예: `a[1] == a[0]`인 경우, 하지만 이 문제에서는 불가능)라면 문제가 될 수 있다.
    - **결론**: 이 줄은 **논리적으로 불필요하지만, 코드 가독성이나 명확성을 위해 추가된 것**으로 보인다. 주석의 "← 이게 빠져있었어요!"는 **잘못된 주석**이다.

```python
print(result)
```
반복문이 끝난 후(또는 `break`로 종료된 후) `result`의 값을 출력한다.

## 외울 것
> **"첫 번째 비교로 방향을 정하고, 이후 반대 방향이 나오면 mixed"**
> 인접한 두 값을 비교할 때, **초기 방향**을 설정하고 **방향 전환**을 감지하는 패턴.
