## 문제
농구 선수의 3가지 기록(점수, 리바운드 등)을 입력받아, 10 이상인 기록의 개수에 따라 특정 단어를 출력하는 문제이다.
1. 입력된 3개의 숫자를 그대로 출력한다.
2. 3개의 숫자 중 10 이상인 숫자의 개수를 센다.
   - 0개: `zilch`
   - 1개: `double`
   - 2개: `double-double`
   - 3개: `triple-double`
3. 각 선수의 출력 결과 뒤에 빈 줄 하나를 출력한다.

## 입력
- 첫째 줄: 선수의 수 `n` (양의 정수)
- 다음 `n`줄: 각 선수의 3가지 기록 (0 이상 100 이하의 정수, 공백으로 구분)

## 출력
- 각 선수에 대해 2줄을 출력한다.
  1. 첫째 줄: 입력받은 3개의 숫자를 공백으로 구분하여 그대로 출력
  2. 둘째 줄: 10 이상인 숫자의 개수에 해당하는 단어 (`zilch`, `double`, `double-double`, `triple-double`)
- 각 선수의 출력 블록 뒤에 빈 줄 하나를 출력한다.

## 예제
```
입력          출력
3             12 5 8
12 5 8        double
0 0 0         zilch
10 10 10      triple-double
```
첫 번째 선수(12, 5, 8)는 12만 10 이상이라 `double`이 출력된다.
두 번째 선수(0, 0, 0)는 10 이상인 것이 없으므로 `zilch`가 출력된다.
세 번째 선수(10, 10, 10)는 모두 10 이상이라 `triple-double`이 출력된다.

## 풀이 아이디어
**핵심 질문: "3개의 숫자 중 10 이상인 것이 몇 개인가?"**

이 문제는 복잡한 알고리즘이 아니라 **조건 분기(if-elif-else)** 로 해결한다.
1. 입력받은 3개의 숫자를 리스트로 저장한다.
2. 리스트를 순회하며 10 이상인 숫자의 개수(`count`)를 센다.
3. `count`의 값(0, 1, 2, 3)에 따라 해당하는 단어를 출력한다.

```
count == 0 -> "zilch"
count == 1 -> "double"
count == 2 -> "double-double"
count == 3 -> "triple-double"
```

## 코드 따라가기
```python
import sys

# 테스트 케이스 개수 입력
n = int(input())

for i in range(n):
    line = sys.stdin.readline().split()
    if not line: break # 빈 줄 예외 처리
    
    nums = list(map(int, line))
    
    # 10 이상인 숫자의 개수 카운트
    count = sum(1 for x in nums if x >= 10)
    
    # 1. 원본 숫자들 출력
    print(f"{nums[0]} {nums[1]} {nums[2]}")
    
    # 2. 개수에 따른 정확한 단어 출력
    if count == 0:
        print("zilch")
    elif count == 1:
        print("double")
    elif count == 2:
        print("double-double")
    elif count == 3:
        print("triple-double")
   
    print()
```

1. **입력 처리**:
   - `n = int(input())`: 몇 명의 선수를 처리할지 입력받는다.
   - `for i in range(n)`: 선수 수만큼 반복한다.
   - `line = sys.stdin.readline().split()`: 한 줄을 읽고 공백 기준으로 리스트로 분리한다.
   - `if not line: break`: 빈 줄이 들어올 경우를 대비해 중단한다 (보통 ACPC에서는 빈 줄이 없으므로 안전장치).
   - `nums = list(map(int, line))`: 분리된 문자열 리스트를 정수 리스트로 변환한다.

2. **카운트 계산**:
   - `count = sum(1 for x in nums if x >= 10)`:
     - 이 줄은 **제너레이터 표현식(generator expression)** 을 `sum()` 함수와 함께 사용한 것이다.
     - `for x in nums if x >= 10`: `nums` 리스트의 각 요소 `x`를 순회하며, `x`가 10 이상인 경우에만 `1`을 생성한다.
     - `sum(...)`: 생성된 1들을 모두 더한다. 즉, 10 이상인 숫자의 개수를 셈에 넣는 것이다.
     - 예: `nums = [12, 5, 8]` 이면, 12는 10 이상이라 1, 5는 아님, 8은 아님 -> `sum(1)` = 1.

3. **출력**:
   - `print(f"{nums[0]} {nums[1]} {nums[2]}")`: f-string을 이용해 첫 번째, 두 번째, 세 번째 숫자를 공백으로 구분해 출력한다.
   - `if-elif-else`: `count` 값에 따라 적절한 단어를 출력한다.
   - `print()`: 아무 인자 없이 호출하면 빈 줄을 출력한다. 문제 요구사항인 "각 선수 출력 후 빈 줄"을 처리한다.

## 외울 것
> **"조건에 맞는 개수 세기"는 `sum(1 for x in list if condition)` 패턴으로 깔끔하게 쓸 수 있다.**
> **출력 형식(빈 줄 포함)을 정확히 지키기 위해 `print()`를 마지막에 꼭 호출한다.**
