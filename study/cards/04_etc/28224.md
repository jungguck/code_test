## 문제
네버랜드(Neverland)의 물가 인플레이션을 고려하여, 특정 기간 동안의 물품 최종 가격을 계산하는 문제이다.
1. 1일차의 초기 가격과, 2일차부터 n일차까지의 일일 가격 변동량(증가/감소)이 주어진다.
2. 초기 가격에 각 일의 변동량을 순서대로 모두 더하여 n일차의 최종 가격을 구한다.

## 입력
- 첫째 줄: 관찰된 일수의 개수 `n` (1 ≤ n ≤ 1000)
- 둘째 줄: 1일차의 초기 가격 (양수 정수)
- 셋째 줄부터 n번째 줄까지: 2일차부터 n일차까지의 일일 가격 변동량 (n-1개)

## 출력
- n일차의 최종 가격 (정수 하나)

## 예제
```
입력          출력
3             105
100
5
0
```
초기 가격 100에 2일차 변동량 5를 더하고, 3일차 변동량 0을 더하면 105가 된다.

## 풀이 아이디어
**핵심 질문: "변동량이 주어졌을 때, 현재 가격에 어떻게 반영해야 하는가?"**
이 문제는 복잡한 알고리즘이 필요 없는 단순한 **누적 합(Accumulation)** 문제이다.
1. 첫 번째 입력 값(초기 가격)을 현재 가격으로 설정한다.
2. 나머지 입력 값들(변동량)을 하나씩 읽으며 현재 가격에 계속 더한다.
3. 모든 변동량을 처리한 후의 값이 최종 가격이다.

```
초기 가격: 100
+ 2일차 변동: 5  -> 105
+ 3일차 변동: 0  -> 105 (최종)
```

## 코드 따라가기
```python
n = int(input())
```
`n`은 관찰된 일수의 총 개수이다. 이 값은 반복 횟수를 결정하는 데 사용된다.

```python
ans = 0
```
최종 가격을 저장할 변수 `ans`를 0으로 초기화한다.

```python
for _ in range(n):
    a = int(input())
    ans += a
```
- `for _ in range(n)`: `n`번 반복한다. `_`는 반복 변수를 따로 저장하지 않고 단순히 횟수만 세겠다는 의미이다.
- `a = int(input())`: 매 반복마다 한 줄씩 입력을 받아 정수로 변환한다.
  - 1번째 반복: 1일차의 **초기 가격**을 입력받는다.
  - 2번째 반복: 2일차의 **변동량**을 입력받는다.
  - ...
  - n번째 반복: n일차의 **변동량**을 입력받는다.
- `ans += a`: 입력받은 값 `a`를 `ans`에 더한다.
  - 1번째 반복 시: `ans = 0 + 초기가격`
  - 2번째 반복 시: `ans = 초기가격 + 2일차변동량`
  - 이 과정이 반복되면 모든 값이 누적된다.

```python
print(ans)
```
모든 입력을 처리하고 누적된 최종 가격 `ans`를 출력한다.

## 외울 것
> **"초기값 + 일일 변동량"이 주어지면, 초기값을 첫 번째 입력으로 보고 나머지 입력을 모두 더하는 단순 누적 합 문제이다.**
