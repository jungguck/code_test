## 문제
H층 W개의 방이 있는 호텔에 N번째 손님이 도착했을 때, 정문에서 가장 가까운 빈 방 번호를 구하는 문제이다.
방 배정 규칙은 다음과 같다:
1. 정문에서 걸어서 가장 가까운 방을 배정한다. (엘리베이터 이동은 무시하고, 같은 층 내에서 이동 거리만 계산)
2. 같은 이동 거리라면 아래층(층수가 작은 곳)을 선호한다.
3. 방 번호는 `층수` + `방번호(2자리)` 형태로 이루어진다. (예: 3층 5호 -> 305)

## 입력
- 첫째 줄: 테스트 케이스의 개수 T
- 다음 T줄: 각 테스트 케이스마다 H(층 수), W(각 층의 방 수), N(N번째 손님)을 공백으로 구분하여 입력

(제약 조건: 1 ≤ H, W ≤ 99, 1 ≤ N ≤ H × W)

## 출력
- 각 테스트 케이스마다 N번째 손님에게 배정될 방 번호를 한 줄씩 출력

## 예제
```
입력          출력
1             402
6 12 10
```
H=6, W=12, N=10인 경우:
1~6번째 손님은 1층부터 6층까지 1호실에 배정됨 (101, 201, ..., 601).
7~12번째 손님은 다시 1층부터 6층까지 2호실에 배정됨.
10번째 손님은 7(1층 2호), 8(2층 2호), 9(3층 2호), 10(4층 2호)이므로 **402**가 된다.

## 풀이 아이디어
**핵심 질문: "N번째 손님은 몇 층의 몇 호실인가?"**

손님들은 층을 순서대로 채워 넣는 것이 아니라, **1호실을 1층부터 H층까지 채운 후, 2호실을 1층부터 H층까지 채우는** 방식으로 배정된다.
즉, 방 번호의 '호실 부분(XX)'은 N을 H로 나눈 몫과 관련이 있고, '층 부분(Y)'은 N을 H로 나눈 나머지와 관련이 있다.

1. **호실 번호(room_line) 찾기**:
   - N번째 손님은 몇 번째 호실(1호, 2호, ...)에 배정되는가?
   - 1호실은 1~H번째 손님, 2호실은 H+1~2H번째 손님...
   - 따라서 `room_line = (N // H) + 1`
   - *주의*: N이 H의 배수인 경우(예: H=6, N=6)는 1호실의 마지막(6층)이므로 `6//6 + 1 = 2`가 되어 2호실로 잘못 계산된다. 이 경우를 보정해야 한다.

2. **층 번호(floor) 찾기**:
   - 해당 호실 안에서 몇 번째 층인가?
   - `floor = N % H`
   - *주의*: N이 H의 배수인 경우(예: H=6, N=6)는 `6%6 = 0`이 되지만, 실제로는 H층(6층)이다. 따라서 나머지가 0이면 H로 보정해야 한다.

3. **방 번호 조합**:
   - 최종 방 번호 = `층번호 * 100 + 호실번호`

```
N=10, H=6, W=12 예시
room_line = 10 // 6 + 1 = 1 + 1 = 2
floor     = 10 % 6 = 4
(floor != 0 이므로 보정 불필요)
방 번호 = 4 * 100 + 2 = 402
```

## 코드 따라가기
```python
t = int(input())

for i in range(t):
    h,w,n = map(int, input().split()) #
```
- `t`: 테스트 케이스 수를 읽는다.
- `for i in range(t)`: T번만큼 반복한다.
- `h,w,n = map(int, input().split())`: 한 줄에 들어온 H, W, N을 정수로 변환하여 변수에 대입한다.

```python
    floor = n%h
    room_line = (n // h) +1
```
- `floor = n%h`: N을 H로 나눈 나머지를 구해 층 번호 후보를 만든다.
- `room_line = (n // h) +1`: N을 H로 나눈 몫에 1을 더해 호실 번호를 만든다. (1부터 시작하므로 +1)

```python
    if floor == 0:
        floor = h
        room_line -= 1
```
- **핵심 보정 로직**: `floor`가 0인 경우, 이는 N이 H의 배수임을 의미한다.
  - 예: H=6, N=6. `6%6=0`이지만 실제 층은 6층이다.
  - 따라서 `floor`를 `h`(최대 층 수)로 수정한다.
  - 동시에, 이 손님은 다음 호실의 1층이 아니라 현재 호실의 마지막 층이므로, `room_line`을 1 감소시킨다.
  - 예: H=6, N=6. 원래 `room_line`은 `6//6+1 = 2`였지만, 실제로는 1호실의 6층이므로 `room_line`은 1이어야 한다.

```python
    print(floor*100 + room_line)
```
- 층 번호에 100을 곱하고 호실 번호를 더하여 최종 방 번호를 출력한다.
- 예: 4층 2호 -> `4*100 + 2 = 402`

## 외울 것
> **"나머지가 0인 경우"는 항상 보정해야 한다.**
> `N % H == 0`이면 층은 `H`층이고, 호실 번호는 `N // H` (즉, `+1`을 하지 않거나, 계산 후 `-1`을 한다).
> 이 문제를 풀 때 가장 많이 틀리는 지점은 이 **경계 조건(Edge Case)** 처리이다.
