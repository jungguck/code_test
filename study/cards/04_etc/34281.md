## 문제
신입생들이 축구장에 모여 단체 사진을 찍으려 한다.
학생들은 직사각형 형태로 줄을 세운다.
직사각형의 폭(width)과 길이(length)가 주어졌을 때,
직사각형 안에 들어가는 학생의 총 수를 구하라.

## 입력
- 첫째 줄: 직사각형의 폭 `a` (정수)
- 둘째 줄: 직사각형의 길이 `b` (정수)

<!-- 확인필요: a, b의 최대 범위를 코드만으로는 알 수 없음 -->

## 출력
- 직사각형 안에 있는 학생의 총 수 (정수) 하나

## 예제
```
입력          출력
3             12
4
```
폭이 3이고 길이가 4인 직사각형에는 $3 \times 4 = 12$ 명의 학생이 들어간다.

## 풀이 아이디어
**핵심 질문: "직사각형의 면적(또는 칸의 개수)은 어떻게 구하는가?"**

직사각형의 한 변의 길이가 $a$, 다른 변의 길이가 $b$일 때,
그 안의 총 칸 수(학생 수)는 두 변의 길이를 곱하면 된다.

$$ \text{총 학생 수} = a \times b $$

이 문제는 복잡한 로직이나 반복문이 필요 없는 가장 기본적인 **사칙연산(곱셈)** 문제이다.

## 코드 따라가기
```python
a = int(input())
```
- `input()`: 사용자의 입력을 문자열 형태로 받아온다.
- `int(...)`: 받아온 문자열을 정수(integer)로 변환한다.
- `a = ...`: 변환된 정수를 변수 `a`에 저장한다.
- **왜 `int()`가 필요한가?** `input()`은 항상 문자열을 반환한다. 문자열끼리는 곱셈(`*`)이 가능하지만(예: `"3" * 4` -> `"3333"`), 숫자 계산이 필요하므로 정수로 변환해야 한다.

```python
b = int(input())
```
- 위와 동일한 방식으로 둘째 줄의 입력을 정수 `b`로 변환하여 저장한다.

```python
print(a*b)
```
- `a*b`: 두 정수 `a`와 `b`를 곱한다.
- `print(...)`: 계산된 결과를 화면에 출력한다.

## 외울 것
> **"직사각형의 크기(폭, 길이)가 주어지면 총 개수는 곱셈"**
> 입력을 받을 때 `int()`로 변환하지 않으면 문자열 곱셈이 되어 틀린 답이 나온다.
