## 문제
문자열 S를 입력받아, S의 각 문자를 R번 반복해서 새 문자열 P를 만든 후 출력하는 프로그램을 작성한다.
1. 첫 번째 문자를 R번 반복하고, 두 번째 문자를 R번 반복하는 식으로 이어 붙인다.
2. S에는 QR Code "alphanumeric" 문자(0-9, A-Z, $%*+-./:)만 들어있다.

## 입력
- 첫째 줄: 테스트 케이스의 개수 T (1 ≤ T ≤ 1,000)
- 다음 T줄: 반복 횟수 R (1 ≤ R ≤ 8)과 문자열 S (길이 1~20)가 공백으로 구분되어 주어진다.

## 출력
- 각 테스트 케이스에 대해 생성된 문자열 P를 한 줄씩 출력한다.

## 예제
```
입력          출력
2             AAABBBCCC
3 ABC         /////HHHHHTTTTTPPPPP
5 /HTP
```
첫 번째 케이스: `A`를 3번, `B`를 3번, `C`를 3번 반복하여 `AAABBBCCC`가 된다.
두 번째 케이스: `/`를 5번, `H`를 5번, `T`를 5번, `P`를 5번 반복하여 `/////HHHHHTTTTTPPPPP`가 된다.

## 풀이 아이디어
**핵심 질문: "각 문자를 R번 반복해서 붙이는 가장 간단한 방법은?"**
파이썬에서는 문자열에 `*` 연산자를 사용하면 문자를 반복할 수 있다.
예를 들어 `'A' * 3`은 `'AAA'`가 된다.
따라서 문자열의 각 문자를 순회하며(`for x in word`), 그 문자를 `R`번 반복한 결과를 바로 출력(`print(..., end='')`)하면 된다.
각 테스트 케이스가 끝나면 줄바꿈(`print()`)을 해주어야 한다.

## 코드 따라가기
```python
n = int(input())
```
첫째 줄에서 테스트 케이스 개수 `n`을 정수로 받아온다.

```python
for _ in range(n):
    cnt, word = input().split()
```
`n`번 반복한다.
각 줄에서 `input().split()`을 호출하면 공백 기준으로 나뉜 리스트가 반환된다.
이 리스트를 `cnt`와 `word` 두 변수에 동시에 대입한다(언패킹).
`cnt`는 반복 횟수 R, `word`는 문자열 S이다.

```python
    for x in word:
        print(x*int(cnt), end = '')
```
`word`의 각 문자 `x`를 순회한다.
`x * int(cnt)`는 문자 `x`를 `cnt`번 반복한 문자열을 만든다.
`print(..., end='')`는 출력 후 줄바꿈 대신 아무것도 넣지 않으므로, 반복된 문자들이 한 줄에 붙어서 출력된다.
`cnt`는 문자열로 들어왔으므로 `int(cnt)`로 정수로 변환해야 곱셈이 가능하다.

```python
    print()
```
한 테스트 케이스의 모든 문자를 출력한 후, 줄바꿈을 수행한다.
이것이 없으면 다음 테스트 케이스의 결과가 같은 줄에 붙어서 출력된다.

## 외울 것
> **"문자열 반복" → `문자 * 횟수`로 생성, `end=''`로 줄바꿈 없이 붙여 출력, 케이스마다 `print()`로 줄바꿈.**
