## 문제
주어진 정수가 팰린드롬수인지 판별하는 문제이다.
1. 팰린드롬이란 앞뒤를 뒤집어도 같은 문자열(또는 수)을 말한다.
2. 입력으로 여러 개의 수가 주어지며, 각 수에 대해 팰린드롬수인지 판별한다.
3. 입력이 `0`이 주어지면 프로그램을 종료한다.

## 입력
- 여러 줄에 걸쳐 1 이상 99,999 이하의 정수가 주어진다.
- 마지막 줄에 `0`이 주어지며, 이 값은 판별 대상이 아니다.

## 출력
- 각 입력 수에 대해 팰린드롬수이면 `yes`, 아니면 `no`를 한 줄씩 출력한다.

## 예제
```
입력          출력
121           yes
123           no
12421         yes
0
```
`121`은 앞뒤가 같으므로 `yes`, `123`은 `321`이 되어 다르므로 `no`, `12421`은 대칭이므로 `yes`이다.

## 풀이 아이디어
**핵심 질문: "앞의 숫자와 뒤의 숫자가 모두 일치하는가?"**

수를 문자열로 변환하여, 가장 앞의 문자와 가장 뒤의 문자를 비교한다.
다음으로 앞의 문자와 다음으로 뒤의 문자를 비교한다.
이 과정을 수의 길이 절반(`len(n)//2`)만큼 반복하면 된다.

```
예시: "12421"
인덱스: 0 1 2 3 4

비교 1: n[0] ('1') vs n[4] ('1') -> 일치
비교 2: n[1] ('2') vs n[3] ('2') -> 일치
(중간 n[2]는 자기 자신과 비교하므로 생략)
-> 모두 일치하므로 팰린드롬
```

만약 하나라도 다르면 팰린드롬이 아니므로 즉시 `no`를 출력하고 다음 입력으로 넘어간다.

## 코드 따라가기
```python
while True:
    n = input()
    if n == '0':
        break
```
- `while True`: 무한 루프를 만들어 계속 입력을 받는다.
- `n = input()`: 한 줄을 문자열로 입력받는다. (숫자로 변환하지 않고 문자열로 유지하는 것이 핵심이다.)
- `if n == '0': break`: 입력이 '0'이면 루프를 빠져나와 프로그램을 종료한다.

```python
    for i in range(len(n)//2):
        if n[i] != n[len(n)-1-i]:
            print("no")
            break
    else:
        print("yes")
```
- `for i in range(len(n)//2)`:
    - `len(n)`: 문자열의 길이.
    - `len(n)//2`: 길이를 2로 나눈 몫. 예를 들어 길이가 5면 2번, 4면 2번 반복한다.
    - `i`는 0부터 시작하여 앞쪽 인덱스를 나타낸다.
- `n[i]`: 앞쪽에서 `i`번째 문자.
- `n[len(n)-1-i]`: 뒤쪽에서 `i`번째 문자.
    - `len(n)-1`은 마지막 인덱스이다.
    - `i`가 0이면 마지막, `i`가 1이면倒数 두 번째, 등등.
- `if n[i] != n[len(n)-1-i]`:
    - 앞뒤 문자가 다르면 팰린드롬이 아니다.
    - `print("no")`를 출력하고 `break`로 `for` 루프를 즉시 종료한다.
- `else`:
    - **`for ... else` 문법**: `for` 루프가 `break`로 중단되지 않고 **모든 반복을 정상적으로 끝냈을 때** 실행되는 블록이다.
    - 즉, 모든 앞뒤 문자가 일치했다는 뜻이므로 `print("yes")`를 출력한다.

## 외울 것
> **"앞뒤 대칭 검사" → 문자열 길이 절반만큼 반복하며 `n[i]`와 `n[-1-i]`를 비교.**
> **`for ... else`는 break 없이 끝났을 때만 실행되는 '모두 성공' 플래그 역할을 한다.**
