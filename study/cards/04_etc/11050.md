## 문제
자연수 $N$과 정수 $K$가 주어졌을 때, 이항 계수 $\binom{N}{K}$를 구하는 프로그램을 작성하시오.
이항 계수는 $N$개의 서로 다른 것 중에서 $K$개를 고르는 방법의 수를 의미하며, 수학적 공식은 다음과 같다.
$$ \binom{N}{K} = \frac{N!}{K!(N-K)!} $$

## 입력
- 첫째 줄: $N$과 $K$ (1 ≤ $N$ ≤ 10, 0 ≤ $K$ ≤ $N$)

## 출력
- $\binom{N}{K}$의 값

## 예제
```
입력          출력
10 2          45
```
$N=10, K=2$일 때, $\frac{10!}{2! \cdot 8!} = \frac{10 \times 9}{2 \times 1} = 45$가 된다.

## 풀이 아이디어
**핵심 질문: "팩토리얼($!$)을 어떻게 효율적으로 계산할 것인가?"**

이항 계수 공식 $\frac{N!}{K!(N-K)!}$을 그대로 구현하면 $N!$을 계산해야 하는데, $N$이 크면 숫자가 매우 커진다.
하지만 이 문제의 $N$은 최대 10이므로, 팩토리얼을 직접 곱해서 구해도 충분하다.

수식을 조금 더 단순화하면 다음과 같다.
$$ \frac{N \times (N-1) \times \dots \times (N-K+1)}{K \times (K-1) \times \dots \times 1} $$
즉, 분모와 분자에서 공통으로 사라지는 $(N-K)!$ 부분을 빼고,
분자는 $N$부터 $K$개만큼 내려가면서 곱하고,
분모는 $1$부터 $K$까지 곱한 값으로 나누면 된다.

코드는 이 과정을 두 번의 반복문으로 나누어 구현한다.
1. `a`: 분자 부분 ($N \times (N-1) \times \dots$)
2. `b`: 분모 부분 ($1 \times 2 \times \dots \times K$)
마지막에 `a // b`로 정수 나눗셈을 수행한다.

## 코드 따라가기

```python
n, k = map(int, input().split())
```
- `input().split()`: 입력받은 문자열을 공백 기준으로 잘라서 리스트로 만든다.
- `map(int, ...)`: 리스트 안의 모든 요소를 정수(`int`)로 변환한다.
- `n, k = ...`: 변환된 값 두 개를 각각 변수 `n`, `k`에 대입한다.

```python
a = 1
b = 1
```
- `a`: 분자(상단)를 저장할 변수. 곱셈의 시작값은 1이다.
- `b`: 분모(하단)를 저장할 변수. 곱셈의 시작값은 1이다.

```python
# n!/(n-k)!
for i in range(n, n-k, -1):
    a *= i  # n, n-1, ..., n-k+1까지 곱셈
```
- `range(n, n-k, -1)`: `n`부터 시작해서 `n-k`보다 큰 숫자까지, 1씩 감소하며 반복한다.
  - 예: `n=10, k=2`라면 `range(10, 8, -1)`이므로 `10, 9` 두 번 반복한다.
- `a *= i`: `a = a * i`의 줄임말. 현재 `a`에 `i`를 곱해서 다시 `a`에 저장한다.
- 이 반복문이 끝나면 `a`에는 $N \times (N-1) \times \dots \times (N-K+1)$ 값이 들어있다.

```python
# k!
for j in range(1, k+1):
    b *= j  # 1부터 k까지 곱셈
```
- `range(1, k+1)`: `1`부터 `k`까지 증가하며 반복한다.
- `b *= j`: `b = b * j`의 줄임말.
- 이 반복문이 끝나면 `b`에는 $1 \times 2 \times \dots \times K$ (즉, $K!$) 값이 들어있다.

```python
# n!/((n-k)!*k!) 계산
print(a // b)  # 나눗셈 연산
```
- `//`: 정수 나눗셈(몫) 연산자이다. 소수점 이하를 버림.
- `a // b`: 분자를 분모로 나누어 최종 이항 계수를 구한다.
- `print(...)`: 결과를 화면에 출력한다.

## 외울 것
> **이항 계수 $\binom{N}{K}$는 "분자 $N$부터 $K$개 곱하기 / 분모 $1$부터 $K$까지 곱하기"로 구현할 수 있다.**
> 팩토리얼 함수를 따로 만들지 않고, `range`와 곱셈 누적(`*=`)으로 간단히 계산하는 패턴을 외운다.
