## 문제
와우산 스탬프 투어의 최종 점수를 계산하는 문제이다.
등산객이 방문한 명소의 개수(N)와 총 걸음 수(W)를 입력받아 다음 규칙에 따라 점수를 계산한다.
1. 방문한 명소 1곳당 10점의 기본 점수를 받는다.
2. 방문한 명소의 개수가 3개 이상이면, 추가로 20점을 받는다.
3. 모든 5개의 명소를 방문했다면, 특별 보너스로 50점을 더 받는다.
4. 총 걸음 수가 1000보를 초과하면, 피로 누적 때문에 15점을 감점한다.
5. 최종 점수는 0점 미만으로 내려가지 않는다.

## 입력
- 첫째 줄: 등산객이 방문한 명소의 개수 N (0 ≤ N ≤ 5)
- 둘째 줄: 등산객의 총 걸음 수 W (0 ≤ W ≤ 2 000)

## 출력
- 계산된 등산객의 최종 '투어 점수'를 출력한다.

## 예제
```
입력          출력
3             50
1000
```
- 기본 점수: 3 * 10 = 30
- 3개 이상 방문 보너스: +20
- 걸음 수 1000은 "초과"가 아니므로 감점 없음
- 최종: 30 + 20 = 50

## 풀이 아이디어
**핵심 질문: "주어진 조건(N, W)에 따라 점수가 어떻게 변하는가?"**
이 문제는 복잡한 알고리즘이 아니라, **조건문(if)을 순서대로 적용**하여 점수를 계산하는 단순 구현 문제이다.

점수 계산 로직을 단계별로 나누면 다음과 같다:
1. **기본 점수**: `N * 10`
2. **조건 1 (3개 이상)**: `N >= 3` 이면 `+20`
3. **조건 2 (5개 전부)**: `N == 5` 이면 `+50`
   - *주의*: 5개 방문 시에는 3개 이상 조건도 만족하므로, 20점과 50점이 **모두** 적용된다.
4. **조건 3 (걸음 수 초과)**: `W > 1000` 이면 `-15`
   - *주의*: "초과"이므로 `1000` 자체는 감점되지 않는다. `>` 기호를 사용해야 한다.
5. **최종 처리**: 점수가 0보다 작아지면 0으로 만든다. `max(point, 0)`

## 코드 따라가기
```python
n = int(input())
w = int(input())
```
- `input()`으로 입력받은 문자열을 `int()`로 정수로 변환한다.
- `n`: 방문한 명소 개수
- `w`: 총 걸음 수

```python
point = 10 * n
```
- 기본 점수를 계산한다. 명소 하나당 10점씩이므로 `10 * n`이다.

```python
if n >= 3:
    point += 20
```
- 방문한 명소 개수가 3개 이상인지 확인한다.
- `>=` (크거나 같다)를 사용해야 한다. 3개일 때도 보너스를 받으므로.
- 조건이 참이면 `point`에 20을 더한다.

```python
if n == 5:
    point += 50
```
- 방문한 명소 개수가 정확히 5개인지 확인한다.
- `==` (같다)를 사용해야 한다. 5개일 때만 특별 보너스가 적용된다.
- 이 조건은 `n >= 3` 조건과 독립적으로 판단된다. 즉, `n`이 5라면 위 `if` 블록과 이 `if` 블록 **둘 다** 실행되어 20점과 50점이 모두 추가된다.

```python
if w > 1000:
    point -= 15
```
- 총 걸음 수가 1000을 **초과**하는지 확인한다.
- `>` (크다)를 사용해야 한다. 문제에서 "1000보를 초과했다면"이라고 했으므로, 정확히 1000일 때는 감점되지 않는다.
- 조건이 참이면 `point`에서 15를 뺀다.

```python
print(max(point, 0))
```
- `max(a, b)` 함수는 a와 b 중 큰 값을 반환한다.
- 여기서 `point`와 `0` 중 큰 값을 출력한다.
- 만약 감점 등으로 `point`가 음수가 되면 `0`을 출력하고, 양수나 0이면 `point`를 출력한다.
- 문제의 "점수는 0점 미만으로 내려가지 않는다"는 조건을 만족시키기 위해 필요하다.

## 외울 것
> **"초과"는 `>`, "이상"은 `>=`, "이하"는 `<=`, "미만"은 `<`**
> 조건문에서 비교 연산자를 잘못 쓰면 경계값(예: 정확히 1000보, 정확히 3개)에서 틀린다.
> 최종 결과가 음수가 될 수 있는 경우 `max(결과, 0)`으로 0을 보장한다.
