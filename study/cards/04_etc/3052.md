## 문제
10개의 자연수를 입력받는다.
각 숫자를 42로 나눈 나머지를 구한 뒤, 그 결과들 중 **서로 다른 값**이 몇 개 있는지 구한다.

## 입력
- 첫째 줄부터 열번째 줄까지: 숫자가 한 줄에 하나씩 주어진다.
- 각 숫자는 1,000보다 작거나 같은 음이 아닌 정수이다.

## 출력
- 첫째 줄에: 42로 나누었을 때, 서로 다른 나머지의 개수

## 예제
```
입력          출력
5             3
10
15
20
25
30
35
40
45
50
```
- 5 % 42 = 5
- 10 % 42 = 10
- 15 % 42 = 15
- 20 % 42 = 20
- 25 % 42 = 25
- 30 % 42 = 30
- 35 % 42 = 35
- 40 % 42 = 40
- 45 % 42 = 3 (45 - 42 = 3)
- 50 % 42 = 8 (50 - 42 = 8)

나머지 목록: `[5, 10, 15, 20, 25, 30, 35, 40, 3, 8]`
이 목록에서 중복을 제거하면 10개 모두 다르므로 답은 10이다.

## 풀이 아이디어
**핵심 질문: "42로 나눈 나머지는 최대 몇 가지가 나올 수 있으며, 중복은 어떻게 제거할까?"**

1.  **나머지의 범위**: 어떤 정수를 42로 나누면 나머지는 `0`부터 `41`까지의 정수만 나올 수 있습니다. 즉, 가능한 나머지는 최대 42가지입니다.
2.  **중복 제거**: 10개의 수를 42로 나눈 나머지를 구했을 때, 같은 값이 여러 번 나올 수 있습니다. 우리는 "서로 다른 값"의 개수를 원하므로, 이미 보았던 나머지는 다시 카운트하지 않아야 합니다.
3.  **방법**:
    *   빈 리스트 `b`를 만들어서 "아직 보지 않은 나머지"들을 저장해 둡니다.
    *   10개의 수를 하나씩 꺼내서 42로 나눈 나머지 `remainder`를 계산합니다.
    *   이 `remainder`가 리스트 `b`에 **이미 있는지** 확인합니다.
    *   없다면, 카운트 `cou`를 1 증가시키고, `remainder`를 리스트 `b`에 추가합니다.
    *   있다면, 아무것도 하지 않습니다 (이미 카운트했으므로).
    *   10개를 모두 처리한 후, `cou`의 값이 바로 서로 다른 나머지의 개수가 됩니다.

## 코드 따라가기

```python
a = []
for i in range(10):
    a.append(int(input()))
```
- `a = []`: 10개의 입력 숫자를 저장할 빈 리스트를 만듭니다.
- `for i in range(10)`: 10번 반복합니다.
- `a.append(int(input()))`: 한 줄씩 입력을 받아 정수로 변환(`int`)한 뒤, 리스트 `a`의 끝에 추가(`append`)합니다.
- **왜 이렇게 하는가?**: 코드가 입력을 한 번에 처리하는 것이 아니라, 10개를 먼저 모두 받아놓고 다음 단계에서 처리하기 위해 리스트에 저장합니다.

```python
b = []
cou = 0
for i in range(10):
    remainder = a[i] % 42
```
- `b = []`: "서로 다른 나머지"들을 저장할 빈 리스트를 만듭니다.
- `cou = 0`: 서로 다른 나머지의 개수를 세기 위한 카운터를 0으로 초기화합니다.
- `for i in range(10)`: 저장된 10개의 숫자(`a[0]`부터 `a[9]`)를 순서대로 꺼냅니다.
- `remainder = a[i] % 42`: 현재 꺼낸 숫자 `a[i]`를 42로 나눈 나머지를 `remainder` 변수에 저장합니다. `%`는 나머지 연산자입니다.

```python
    if remainder not in b:
        cou += 1
        b.append(remainder)
```
- `if remainder not in b:`: **핵심 문법**. `in` 연산자는 리스트 안에 특정 값이 있는지 확인합니다. `not in`은 반대로 "리스트 안에 **없는지**" 확인합니다.
- 만약 `remainder`가 리스트 `b`에 **없다면** (아직 보지 않은 새로운 나머지라면):
    - `cou += 1`: 서로 다른 나머지의 개수를 1 증가시킵니다.
    - `b.append(remainder)`: 이 새로운 나머지를 리스트 `b`에 추가합니다. 이렇게 하면 다음에 같은 나머지가 나오면 `in b`가 참이 되어 카운트되지 않습니다.
- 만약 `remainder`가 리스트 `b`에 **있다면** (이미 보았던 나머지라면):
    - `if` 블록 안의 코드가 실행되지 않아, 카운트는 증가하지 않고 리스트에도 추가되지 않습니다.

```python
print(cou)
```
- 10개의 숫자를 모두 처리한 후, 최종적으로 세운 서로 다른 나머지의 개수 `cou`를 출력합니다.

## 외울 것
> **"서로 다른 값의 개수"를 구할 때는, 이미 본 값을 저장해두고(`list` 또는 `set`), 새로운 값이 나올 때만 카운트한다.**
> `if value not in list:` 패턴은 중복을 제거하며 카운트할 때 유용하다.
