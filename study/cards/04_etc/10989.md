## 문제
N개의 수가 주어졌을 때, 이를 오름차순으로 정렬하는 프로그램을 작성하시오.

## 입력
- 첫째 줄: 수의 개수 N (1 ≤ N ≤ 10,000,000)
- 둘째 줄부터 N개의 줄: 각 줄마다 10,000보다 작거나 같은 자연수

## 출력
- 첫째 줄부터 N개의 줄에 오름차순으로 정렬한 결과를 한 줄에 하나씩 출력

## 예제
```
입력          출력
5             1
1             1
2             2
3             3
1             4
4             5
```
(참고: 위 예제는 문제 원문에 없는 가상의 예시입니다. 실제 BOJ 10989 예제는 N=5, 입력값 1,2,3,1,4일 때 1,1,2,3,4가 출력됩니다.)
`1`이 두 번 있으므로 `1`이 두 줄 출력되고, 나머지 숫자는 하나씩 오름차순으로 출력됩니다.

## 풀이 아이디어
**핵심 질문: "N이 1,000만 개까지 크면 `sort()`를 쓰면 안 된다. 왜?"**
파이썬의 기본 정렬(`sort()`)은 시간 복잡도가 O(N log N)입니다. N이 1,000만 개면 log N이 약 20이므로, 약 2,000만 번의 비교가 필요합니다. 하지만 이 문제는 **입력되는 수의 범위가 10,000 이하**라는 제한이 있습니다.

이때 **계수 정렬(Counting Sort)** 을 사용하면 O(N + K) (K는 최대 값)에 해결할 수 있습니다.
1. **개수 세기**: 1부터 10,000까지의 숫자가 각각 몇 번 나왔는지 세어둡니다.
2. **출력**: 1번부터 10,000번까지 순서대로, 그 숫자가 몇 번 나왔는지만큼 출력합니다.

```
숫자:  1   2   3   4   5
개수:  2   1   1   1   0
```
위처럼 개수를 세어두면, 정렬을 안 해도 순서대로 출력만 하면 정렬이 끝납니다.

## 코드 따라가기
```python
import sys
input = sys.stdin.readline
```
`sys.stdin.readline`을 `input`으로 재정의합니다.
**왜?** `input()` 함수는 한 줄을 읽을 때마다 내부적으로 버퍼링 처리를 하여 느립니다. N이 1,000만 개일 때 `input()`을 쓰면 시간 초과(TLE)가 납니다. `sys.stdin.readline`은 훨씬 빠르게 입력을 읽습니다.

```python
n = int(input())
count = [0] * 10001
```
- `n = int(input())`: 첫째 줄에서 N을 읽습니다.
- `count = [0] * 10001`: 길이가 10,001인 리스트를 만들고 모든 값을 0으로 채웁니다.
  - **왜 10,001?** 수의 범위는 1~10,000입니다. 리스트 인덱스는 0부터 시작하므로, `count[10000]`에 접근하려면 리스트 길이는 최소 10,001이어야 합니다. (인덱스 0은 사용하지 않거나 0번 숫자를 위해 남겨둡니다. 문제에서 자연수라고 했으므로 1부터 시작합니다.)

```python
for _ in range(n):
    x = int(input())
    count[x] += 1
```
- N번 반복합니다.
- `x = int(input())`: 한 줄씩 숫자를 읽습니다.
- `count[x] += 1`: 읽은 숫자 `x`가 몇 번 나왔는지 `count` 리스트의 해당 인덱스에 1을 더합니다.
  - 예: `x`가 3이면 `count[3]`에 1을 더합니다.

```python
for i in range(1, 10001):
    for _ in range(count[i]):
        print(i)
```
- `for i in range(1, 10001)`: 1부터 10,000까지 순서대로 숫자를 확인합니다.
- `for _ in range(count[i])`: 숫자 `i`가 `count[i]`번 나왔으므로, 그 횟수만큼 반복합니다.
- `print(i)`: 숫자 `i`를 출력합니다.
  - 예: `count[1]`이 2라면, `i=1`일 때 `print(1)`이 두 번 실행되어 `1`이 두 줄 출력됩니다.

## 외울 것
> **"입력 값의 범위가 작고(N은 크고) N이 매우 클 때" → `sort()` 대신 `counting sort`를 쓰자.**
> **`sys.stdin.readline`을 쓰지 않으면 N이 100만 이상일 때 시간 초과가 날 수 있다.**
