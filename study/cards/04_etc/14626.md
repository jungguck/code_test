## 문제
13자리 ISBN 번호가 주어진다. 이 번호 중 한 자리는 `*`로 훼손되어 있다.
ISBN의 규칙에 따르면, 각 자리에 가중치 1, 3, 1, 3, ... 을 곱하여 모두 더한 값이 10의 배수가 되어야 한다.
즉, `a + 3b + c + 3d + ... + m ≡ 0 (mod 10)` 이다.
훼손된 자리(`*`)에 들어갈 숫자를 찾아 출력한다.

## 입력
- 첫째 줄: 13자리의 문자열 (숫자와 `*`가 섞여 있음)

## 출력
- 훼손된 자리에 들어갈 숫자 하나 (0~9)

## 예제
```
입력          출력
12345678901*  0
```
(가정) `1+3*2+3+3*4+5+3*6+7+3*8+9+3*0+1 = 60`.
`60 + m` 이 10의 배수가 되려면 `m` 은 0이어야 한다.

## 풀이 아이디어
**핵심 질문: "훼손된 자리의 가중치는 몇이고, 나머지 숫자들의 합은 얼마인가?"**

1.  **가중치 패턴**: ISBN은 13자리이다.
    -   0번째, 2번째, 4번째... (짝수 인덱스) → 가중치 **1**
    -   1번째, 3번째, 5번째... (홀수 인덱스) → 가중치 **3**
2.  **전략**:
    -   `*`가 아닌 나머지 12개의 숫자만 먼저 가중치를 곱해서 합을 구한다.
    -   `*`가 있는 위치의 인덱스(`star_idx`)를 기억해둔다.
    -   `*` 자리에 0부터 9까지 대입해 본다.
    -   `(나머지 합 + 대입한 숫자 * 해당 위치의 가중치) % 10 == 0` 을 만족하는 숫자가 정답이다.

## 코드 따라가기

```python
isbn = input()
star_idx = 0
total_sum = 0
```
-   `isbn`: 입력받은 13자리 문자열.
-   `star_idx`: `*`가 있는 위치의 인덱스(0~12)를 저장할 변수.
-   `total_sum`: `*`를 제외한 나머지 숫자들의 가중치 합을 저장할 변수.

```python
# 1. 별 위치 찾고, 나머지 합 구하기
for i in range(13):
    if isbn[i] == '*':
        star_idx = i
    else:
        num = int(isbn[i])
        if i % 2 == 0:
            total_sum += num
        else:
            total_sum += num * 3
```
-   `range(13)`: 0부터 12까지의 인덱스를 순회한다.
-   `isbn[i] == '*'`: 현재 자리가 훼손된 숫자인지 확인한다.
    -   맞으면 `star_idx`에 현재 인덱스 `i`를 저장한다.
-   `else`: 숫자라면 `int()` 로 정수로 변환한다.
-   `i % 2 == 0`: 인덱스가 짝수면 가중치 1, 홀수면 가중치 3을 곱해 `total_sum` 에 더한다.
    -   *초보 주의*: `int(isbn[i])` 는 문자열의 한 글자를 정수로 바꾸는 것이다.

```python
# 2. 별 자리에 0~9 대입해서 정답 찾기 (이게 j 반복문!)
for j in range(10):
    weight = 1 if star_idx % 2 == 0 else 3
    if (total_sum + j * weight) % 10 == 0:
        print(j)
        break
```
-   `for j in range(10)`: `*` 자리에 들어갈 수 있는 숫자 0, 1, ..., 9를 하나씩 시도한다.
-   `weight = 1 if star_idx % 2 == 0 else 3`:
    -   **삼항 연산자** 문법이다. "만약 `star_idx` 가 짝수라면 1, 아니면 3" 이라는 뜻이다.
    -   `*`가 있는 위치의 가중치를 결정한다.
-   `if (total_sum + j * weight) % 10 == 0`:
    -   지금까지 구한 합(`total_sum`)에, 시도 중인 숫자(`j`)를 그 위치의 가중치(`weight`)와 곱한 값을 더한다.
    -   이 결과가 10으로 나누어 떨어지는지(나머지가 0인지) 확인한다.
-   `print(j)`: 조건을 만족하면 그 숫자를 출력한다.
-   `break`: 정답을 찾았으므로 더 이상 반복하지 않고 종료한다.

## 외울 것
> **"부분 합 + 미지수 탐색" 패턴: 전체 합이 특정 조건(10의 배수 등)을 만족해야 할 때, 알 수 없는 한 변수를 제외한 나머지 합을 먼저 구해두고, 미지수에 0~9를 대입하며 검증한다.**
