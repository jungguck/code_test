## 문제
선수들이 달리기를 하고 있다. 해설진은 **앞 사람을 추월한 선수의 이름**을 부른다.
"kai" 를 부르면 kai 가 바로 앞 선수를 제치고 한 칸 앞으로 간다.

처음 등수 순서대로 선 이름 목록 `players` 와, 해설진이 부른 이름 목록 `callings` 가 주어질 때
경주가 끝난 뒤의 등수 순서대로 이름을 담은 리스트를 return 하라.
(1등 선수는 불리지 않는다.)

## 입력
- `players` : 처음 등수 순서의 이름 리스트 (5 ≤ 길이 ≤ **50,000**)
- `callings` : 부른 이름 리스트 (2 ≤ 길이 ≤ **1,000,000**)
- 함수 `solution(players, callings)` 을 채우는 문제 → `input()` 을 안 쓴다

## 출력
- 최종 등수 순서의 이름 리스트를 **return**

## 예제
```
players   ["mumu", "soe", "poe", "kai", "mine"]
callings  ["kai", "kai", "mine", "mine"]
result    ["mumu", "kai", "mine", "soe", "poe"]
```
```
처음          mumu soe  poe  kai  mine
kai  부름  →  mumu soe  kai  poe  mine
kai  부름  →  mumu kai  soe  poe  mine
mine 부름  →  mumu kai  soe  mine poe
mine 부름  →  mumu kai  mine soe  poe
```

## 풀이 아이디어
**핵심 질문: "불린 사람이 지금 몇 번 자리에 있지?" 를 빨리 알아내기**

자리만 알면 할 일은 간단하다 → 그 자리와 **바로 앞 자리**를 바꾼다.

**느린 방법 — `players.index(call)`**
`index()` 는 1등부터 꼴등까지 한 명씩 "너가 kai 니?" 하고 확인한다.
선수 5만 명 × 부르기 100만 번 = 최대 **500억 번** 확인 → **시간 초과.**

**빠른 방법 — 장부(딕셔너리)를 미리 만든다**
경기 전에 **딱 한 번** 5만 명을 훑어서 `이름 → 자리` 장부를 적어 둔다.
```
player_dict = {"mumu": 0, "soe": 1, "poe": 2, "kai": 3, "mine": 4}
```
그러면 `player_dict["kai"]` 한 번에 `3` 이 바로 나온다. (사람을 뒤지지 않는다)

**대신 자리를 바꿀 때마다 두 군데를 다 고쳐야 한다**
- 명단(리스트) `players` : 두 사람 자리 바꾸기
- 장부(딕셔너리) `player_dict` : 두 사람의 자리 번호 바꿔 적기

둘 중 하나라도 안 고치면 다음 번 부를 때 엉뚱한 자리를 찾는다.

**따라가기 — 첫 번째 "kai"**

| 단계 | 값 |
|---|---|
| `idx = player_dict["kai"]` | 3 |
| `prev_player = players[2]` | "poe" |
| 리스트 자리 바꾸기 | mumu soe **kai poe** mine |
| 장부 고치기 | kai → 2, poe → 3 |

## 코드 따라가기
```python
    player_dict = {}
```
텅 빈 딕셔너리(장부)를 하나 만든다.

```python
    for i in range(len(players)):
        player = players[i]
        player_dict[player] = i
```
`장부이름[찾을이름] = 저장할값` — 딕셔너리에 **새로 적어 넣는** 문법이다.
`player_dict[player] = i` = "장부에 이 선수는 i 번 자리에 있다고 적어라".

| 바퀴 | i | player | 적은 뒤 장부 |
|:-:|:-:|---|---|
| 처음 | – | – | `{}` |
| 1 | 0 | "mumu" | `{"mumu": 0}` |
| 2 | 1 | "soe" | `{"mumu": 0, "soe": 1}` |
| 3 | 2 | "poe" | `{"mumu": 0, "soe": 1, "poe": 2}` |

콜론 `:` 왼쪽이 **찾을 이름표(key)**, 오른쪽이 **기억할 값(value)**, 짝마다 쉼표로 구분한다.

```python
    for call in callings:
```
부른 이름을 하나씩 처리한다. 예제는 callings 가 4개라 4번 돈다.
**첫 번째 for 와 같은 높이(들여쓰기)여야 한다.** 장부를 끝까지 다 만든 **다음에** 처리해야 하니까.

```python
        idx = player_dict[call]
        prev_player = players[idx - 1]
```
장부에서 불린 사람의 자리를 바로 꺼내고, 그 **바로 앞 사람의 이름**을 기억해 둔다.
(자리를 바꾸고 나면 `players[idx - 1]` 은 불린 사람으로 바뀌어 버리므로 **바꾸기 전에** 기억)

```python
        players[idx - 1], players[idx] = players[idx], players[idx - 1]
```
파이썬의 동시 대입 — 오른쪽을 먼저 다 계산한 뒤 왼쪽에 넣으므로 임시 변수 없이 두 칸이 바뀐다.

```python
        player_dict[call] = idx - 1
        player_dict[prev_player] = idx
```
이미 있는 이름에 `=` 하면 **새로 추가가 아니라 값 덮어쓰기**다.
불린 사람은 한 칸 앞(`idx - 1`), 추월당한 사람은 한 칸 뒤(`idx`).

```python
    return players
```
두 for 가 다 끝난 뒤, 함수 맨 바깥 높이에서 return.

### 헷갈렸던 것 모음
| 헷갈린 것 | 답 |
|---|---|
| 처음에 굳이 for 로 장부를 만들어야 하나? | **속도 때문.** 없으면 부를 때마다 `index()` 로 처음부터 찾음 → 최대 500억 번 → 시간 초과 |
| `player_dict[player] = i` 가 뭐야? | 장부에 `이름: 자리` 한 줄 적기. `player_dict["soe"] = 1` → `{"soe": 1}` |
| `{(soe : 1)}` 로 저장되나? | 아니다. 소괄호 없이, 이름에 따옴표 → `{"soe": 1}` |
| `for call in callings` 를 첫 for **안에** 넣으면? | 장부에 mumu 하나만 적힌 상태에서 "kai" 를 찾음 → **`KeyError`**. 두 for 는 **같은 높이로 따로** |
| `{player: i for i, player in enumerate(players)}` 는? | 첫 for 세 줄을 **한 줄로** 쓴 것(딕셔너리 컴프리헨션). `enumerate` 가 `(0, "mumu"), (1, "soe")…` 처럼 자리와 이름을 같이 준다. 결과는 똑같으니 이해 안 되면 세 줄짜리로 써도 된다 |
| `prev_player` 를 왜 미리 꺼내? | 자리를 바꾸고 나면 `players[idx - 1]` 자리에 불린 사람이 와 있어서, 추월당한 사람이 누군지 알 수 없다 |

## 외울 것
> **"이름으로 자리를 찾는다" = 딕셔너리 장부를 먼저 한 번 만든다. `index()` 는 매번 처음부터 뒤져서 느리다.**
> **장부 만들기 for 와 처리 for 는 같은 높이로 따로 — 장부를 다 만든 뒤에 처리.**
> **자리를 바꾸면 리스트와 장부 두 군데를 같이 고친다. 앞 사람 이름은 바꾸기 전에 기억.**
