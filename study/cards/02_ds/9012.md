## 문제
`(` 와 `)` 로만 이루어진 문자열이 주어진다.

괄호가 **올바르게 짝지어졌으면** `YES`, 아니면 `NO` 를 출력하라.

올바른 괄호란 — 여는 괄호마다 자기 뒤에 짝이 되는 닫는 괄호가 있고,
순서가 꼬이지 않은 것을 말한다.
```
(())()      올바름
(()(          올바르지 않음 (여는 게 남았다)
)(            올바르지 않음 (순서가 꼬였다)
```

## 입력
- 첫째 줄: 테스트 케이스 개수 T
- 다음 T줄: 각각 괄호 문자열 (길이 50 이하)

## 출력
- 각 줄마다 `YES` 또는 `NO`

## 예제
```
입력                      출력
6                         NO
(())())                   NO
(((()())()                YES
(()())((()))              NO
((()()(()))(((())))()     YES
()()()()(()()())()        NO
(()((())()(
```

## 풀이 아이디어

교과서적인 답은 **스택**이다. `(` 를 쌓고 `)` 를 만나면 하나 꺼낸다.

그런데 **괄호 종류가 한 가지뿐이면** 스택에 뭘 쌓든 전부 `(` 다.
그러면 굳이 쌓을 필요 없이 **개수만 세면 된다.** 이 코드가 그걸 한다.

```
(  를 만나면  cnt += 1      "열린 게 하나 늘었다"
)  를 만나면  cnt -= 1      "하나 닫았다"
```

판정은 두 가지를 본다.

```
① 도중에 cnt 가 음수가 되면  →  NO
   닫는 게 여는 것보다 많아진 순간이다. 예: ")("
   ) 를 만났는데 cnt 가 -1  →  짝지을 게 없는데 닫았다

② 끝까지 갔는데 cnt 가 0 이 아니면  →  NO
   여는 걸 남겨두고 끝난 것이다. 예: "(()("  →  cnt 가 1 로 끝남

둘 다 통과하면  →  YES
```

> ⚠️ ①을 빼먹으면 `)(` 가 YES 로 나온다. 합은 0이지만 순서가 틀렸다.
> **도중에 음수가 되는지**를 꼭 봐야 한다.

## 코드 따라가기

```python
cnt += 1 if c == '(' else -1
```
한 줄 삼항식이다. 풀어 쓰면 이것과 같다.
```python
if c == '(':
    cnt += 1
else:
    cnt -= 1
```

```python
    for c in testcase:
        ...
        if cnt < 0:
            result += "NO\n"
            break
    else:
        result += "YES\n" if cnt == 0 else "NO\n"
```
**`for ... else` 는 파이썬에만 있는 문법이다.** 헷갈리기로 악명 높다.

> `else` 는 **`for` 가 `break` 없이 끝까지 다 돌았을 때만** 실행된다.

```
중간에 cnt < 0  →  break  →  else 를 건너뛴다        (이미 NO 를 적었으니까)
끝까지 무사통과  →  break 없음  →  else 실행         (cnt 가 0인지 확인)
```
`if/else` 의 else 가 아니라 **"break 안 했으면"** 이라는 뜻이다.

```python
result += "YES\n"
...
print(result)
```
매번 `print` 하지 않고 문자열에 모았다가 **마지막에 한 번만** 출력한다.
`print` 는 호출할 때마다 화면에 내보내는 비용이 있어서, 줄이 많으면 이게 쌓여 느려진다.
경쟁적 프로그래밍에서 자주 쓰는 습관이다.

## 외울 것
> **괄호 종류가 하나면 스택 대신 카운터.** `(` 는 +1, `)` 는 -1
>
> **중간에 음수 = NO**, **끝에 0이 아니면 = NO**. 이 두 개를 다 봐야 한다
>
> 괄호가 여러 종류(`()[]{}`)면 그때는 **진짜 스택**이 필요하다
