## 문제
다음과 같은 양의 정수 수열 A 를 **산불 수열** 이라고 한다.
- `A[0] = 1`, `A[1] = 1`
- i ≥ 2 이면, `A[i]` 는 **가능한 모든 k** 에 대해 `A[i-2k], A[i-k], A[i]` 세 수가 **등차수열이 되지 않는 가장 작은 양의 정수**다.
  즉 `A[i] - A[i-k] ≠ A[i-k] - A[i-2k]` 를 모두 만족해야 한다.

산불 수열의 n번 항을 구하라.

## 입력
- 첫째 줄: 테스트 케이스의 개수 TC
- 다음 TC줄: 각 줄에 정수 n (0 ≤ n ≤ 1000)

## 출력
- 테스트 케이스마다 한 줄씩 `A[n]` 을 출력한다 (`#t` 없음)

## 예제
```
입력      출력
5         1
0         1
1         2
5         4
8         4
100
```
수열 앞부분: `A[0..10] = 1 1 2 1 1 2 2 4 4 1 1`

## 풀이 아이디어
**핵심 질문: "1을 넣어도 되나? 안 되면 2는? 3은? …"**

규칙이 "조건을 만족하는 **가장 작은** 수" 이므로, **1부터 하나씩 대보고 처음 통과한 수가 답**이다.
(분해합 2231 과 같은 모양의 완전탐색이다.)

**① k 는 어디까지 보나?**
`A[i-2k]` 가 존재하려면 `i - 2k ≥ 0`, 즉 `k ≤ i // 2`.
→ k 는 `1, 2, …, i//2` 를 전부 검사한다.

**② "등차수열이 된다" 를 코드로**
세 수 `A[i-2k], A[i-k], 후보` 가 같은 간격이면 등차수열이다.
```
a = A[i-k] - A[i-2k]    (앞 간격)
b = 후보   - A[i-k]     (뒤 간격)
a == b 이면 → 이 후보는 탈락
```

**③ 앞에서부터 차례로 채운다**
`A[i]` 를 구하려면 `A[i-1], A[i-2], …` 가 먼저 있어야 한다.
그래서 `A[2], A[3], …, A[n]` 순서로 리스트에 하나씩 붙여 나간다.

**따라가기 — `A[7]` 구하기** (지금까지 `1 1 2 1 1 2 2`, k = 1~3)

| k | A[i-2k] | A[i-k] | 앞 간격 a | 이 값이면 탈락 (A[i-k] + a) |
|---|---|---|---|---|
| 1 | A[5]=2 | A[6]=2 | 0 | 2 |
| 2 | A[3]=1 | A[5]=2 | 1 | 3 |
| 3 | A[1]=1 | A[4]=1 | 0 | 1 |

탈락: 1, 2, 3 → 후보 1(탈락) → 2(탈락) → 3(탈락) → **4 통과**. 그래서 `A[7] = 4`.

## 코드 따라가기
```python
T = int(input())

for test_case in range(1, T + 1):
    n = int(input())
```
테스트 케이스 개수를 받고, 케이스마다 n 을 받는다.
출력에 `#1` 같은 번호를 안 쓰므로 `test_case` 는 실제로 쓰이지 않는다.

```python
    sequence = [1, 1]
```
`A[0] = 1`, `A[1] = 1` 을 미리 넣어 둔다. 이제 `sequence[i]` 가 곧 `A[i]` 다.

```python
    for i in range(2, n+1):
        k = i//2
        result = 1
```
- `i` : 이번에 구할 항 번호. 2번부터 n번까지.
- `k = i//2` : 검사할 k 의 **최댓값** (`//` 는 몫만 남기는 나눗셈. `7//2` → 3)
- `result = 1` : 후보. 가장 작은 양의 정수 1부터 시작한다.

n 이 0 이나 1 이면 `range(2, 1)` 이 **비어 있어서** 반복을 한 번도 안 하고 바로 출력으로 간다.

```python
        while True:
            satisfied = True
```
`while True` : 답을 찾을 때까지 계속 돈다. 안에서 `break` 로 빠져나간다.
`satisfied = True` : "이 후보는 일단 통과" 라고 **깃발을 세워 두고** 시작한다.
검사 중 하나라도 걸리면 깃발을 내린다(`False`). 이런 변수를 **플래그 변수**라고 한다.

```python
            for j in range(1, k+1):
                a = sequence[i-j] - sequence[i-2*j]
                b = result - sequence[i-j]
                if a == b:
                    satisfied = False
                    break
```
문제의 k 를 코드에서는 `j` 로 쓴다 (`k` 라는 이름은 이미 최댓값에 썼으니까).
- `a` : 앞 간격 `A[i-j] - A[i-2j]`
- `b` : 뒤 간격 `후보 - A[i-j]`
- 같으면 등차수열 → 깃발 내리고 `break`. **하나만 걸려도 탈락**이라 나머지 j 는 볼 필요가 없다.

```python
            if satisfied == True:
                sequence.append(result)
                break
            else:
                result += 1
```
- 깃발이 그대로 `True` → 모든 j 를 통과했다 → 리스트 끝에 붙이고(`append`) `while` 탈출.
- 깃발이 `False` → 후보를 1 올려서 `while` 처음으로 돌아가 다시 검사.

여기 `break` 는 **`while True` 를 끝낸다.** 위의 `for j` 안 `break` 는 `for j` 만 끝낸다.
`break` 는 **자기를 감싼 가장 가까운 반복문 하나만** 빠져나간다.

```python
    print(sequence[n])
```
n번째 항을 출력한다.

## 이 코드의 버그
틀린 답은 없다. 예제 5개 모두 맞는다. 대신 알아둘 것 두 가지.

| 코드 | 이야기 |
|---|---|
| `if satisfied == True:` | `if satisfied:` 와 똑같다. 이미 True/False 인 값을 `== True` 로 또 비교할 필요는 없다 |
| 케이스마다 `sequence = [1, 1]` 부터 다시 만든다 | 수열은 n 과 상관없이 **항상 똑같다.** n=1000 한 번에 약 0.5초라 케이스가 많으면 느려진다. 처음에 `A[1000]` 까지 한 번만 만들어 두고 케이스마다 `print(sequence[n])` 만 하면 훨씬 빠르다 |

## 외울 것
> **"조건을 만족하는 가장 작은 수" → 1부터 하나씩 대보고 처음 통과한 수가 답 (완전탐색).**
> **검사 여러 개 중 하나라도 걸리면 탈락 → `ok = True` 깃발 세우고, 걸리면 `False` + `break`.**
> **`break` 는 가장 가까운 반복문 하나만 빠져나간다.**
