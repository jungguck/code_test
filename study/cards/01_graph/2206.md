## 문제
N×M 격자 지도가 있다. `0` 은 이동할 수 있는 칸, `1` 은 벽이다.
`(0,0)` 에서 출발해 `(N-1, M-1)` 까지 **상하좌우로만** 이동한다.

이동 중 벽을 **최대 한 개까지 부수고** 지나갈 수 있다.
시작 칸과 끝 칸을 **모두 포함**해서, 지나는 **칸 수가 가장 적은 경로의 길이**를 구하라.
갈 수 없으면 -1.

## 입력
- 첫째 줄: N, M
- 다음 N줄: `0`/`1` 이 공백 없이 붙은 문자열 한 줄씩

## 출력
- 최단 경로의 칸 수. 불가능하면 -1

## 예제
```
입력            출력
6 4             15
0100
1110
1000
0000
0111
0000
```
벽을 딱 한 번 부수고 돌아가면 시작·끝 포함 **15칸**으로 도착할 수 있다.

## 풀이 아이디어

**이 문제의 핵심 질문: "같은 칸이라도 '벽을 아직 안 부쉈나 / 이미 부쉈나'는 다른 상황이다."**

보통 BFS의 `visited[r][c]` 는 2차원이다. 그런데 여기선 같은 칸 `(r,c)` 에
**"벽 부술 기회가 남은 채로" 온 것**과 **"이미 다 써버리고" 온 것**이 완전히 다른 상태다.
기회가 남아 있으면 앞으로 벽을 뚫을 수 있으니까.

그래서 방문 배열에 **차원을 하나 더** 붙인다.
```
visited[r][c][k]      k = 1 : 아직 벽 부술 수 있음
                      k = 0 : 이미 벽을 부숨
```

이제 한 칸을 최대 **두 번**(k=1일 때, k=0일 때) 방문할 수 있고, 각각을 다른 칸처럼 다룬다.
이렇게 "상태를 좌표에 덧붙이는" 것이 이 유형의 전부다. (벽 부수기 K번 버전이면 `[k+1]` 차원)

BFS(큐)로 퍼지므로 **처음 도착한 순간이 곧 최단**이다.

## 코드 따라가기

```python
visited = [[[0]*2 for _ in range(m)] for _ in range(n)]
q.append((row, col, 1))          # (행, 열, 아직 부술 수 있음=1)
visited[row][col][1] = 1         # 거리를 1부터 (시작 칸도 세니까)
```
`visited[n][m][2]` — 마지막 `2` 가 "부술 기회 남았나(1) / 없나(0)" 두 상태.
거리를 0이 아니라 **1**부터 시작하는 건 "칸 수" 를 세기 때문이다(시작 칸 포함).

```python
if visited[drow][dcol][is_able] == 0 and G[drow][dcol] == '0':
    visited[drow][dcol][is_able] = visited[r][c][is_able] + 1
    q.append((drow, dcol, is_able))
```
빈 칸(`'0'`)이면 **같은 상태 그대로** 이동한다. `is_able` 은 안 바뀐다.

```python
elif is_able == 1 and G[drow][dcol] == '1':
    visited[drow][dcol][0] = visited[r][c][1] + 1
    q.append((drow, dcol, 0))
```
벽(`'1'`)이고 **아직 부술 기회가 있으면(is_able==1)**, 부수고 들어간다.
이때 상태가 **`0`(기회 소진)** 으로 바뀌어 큐에 들어간다. 여기서 차원이 갈린다.

```python
shortest = visited[n-1][m-1]     # [부수고 도착한 거리, 안 부수고 도착한 거리]
```
도착 칸을 두 상태로 확인한다. 둘 중 **0이 아닌 값 중 더 작은 것**이 답이고,
둘 다 0이면 (=한 번도 도착 못 함) **-1**.

## ⚠️ 이 코드의 버그
버그는 아니지만 **마지막 답 고르는 부분이 지나치게 복잡**하다.
```python
if shortest[0] > shortest[1]:
    return_val = shortest[1]
    if return_val == 0: return_val = shortest[0]
else:
    ...
```
`0` 은 "도착 못 함" 을 뜻하므로 **0을 빼고 최솟값**을 고르면 그만이다. 이렇게 쓰면 한 줄이다.
```python
cands = [d for d in shortest if d > 0]
return min(cands) if cands else -1
```
결과는 같지만 이쪽이 실수할 여지가 없다.

## 외울 것
> **같은 칸이라도 '조건이 다르면' 다른 칸이다 → `visited` 에 상태 차원을 추가**
> (`visited[r][c][부순횟수]`). 벽 K번이면 `[K+1]` 로 늘리면 그대로 확장된다.
