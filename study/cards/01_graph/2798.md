## 문제
N장의 카드가 있고, 각 카드에는 양의 정수가 적혀 있다.
이 중 3장의 카드를 골라 합을 구해야 한다.
1. 카드 3장의 합은 M을 넘지 않아야 한다.
2. M을 넘지 않는 조건에서, 합이 M에 최대한 가깝게(최대) 되도록 골라야 한다.
이 최대 합을 구하시오.

## 입력
- 첫째 줄: 카드의 개수 N (3 ≤ N ≤ 100)과 숫자 M (10 ≤ M ≤ 300,000)
- 둘째 줄: N장의 카드에 적힌 숫자 (100,000을 넘지 않는 양의 정수)

## 출력
- M을 넘지 않으면서 M에 최대한 가까운 카드 3장의 합

## 예제
```
입력          출력
5 21
5 6 7 8 9     21
```
`5 + 7 + 9 = 21` 또는 `6 + 7 + 8 = 21` 등 합이 21이 되는 조합이 존재하므로 21이 출력된다.

## 풀이 아이디어
**핵심 질문: "N장 중 3장을 고르는 모든 경우의 수를 다 확인하면 되지 않을까?"**

N이 100 이하이므로, 3중 반복문을 사용하여 모든 조합을 확인하는 **완전탐색(Brute Force)** 이 가능하다.
1. 첫 번째 카드 인덱스 `i`를 0부터 N-1까지 순회한다.
2. 두 번째 카드 인덱스 `j`를 `i+1`부터 N-1까지 순회한다. (이미 고른 카드와 중복되지 않도록)
3. 세 번째 카드 인덱스 `z`를 `j+1`부터 N-1까지 순회한다.
4. `arr[i] + arr[j] + arr[z]`의 합이 `M` 이하인지 확인한다.
5. 조건을 만족하면, 지금까지 구한 최대값 `MAX`와 비교하여 더 큰 값으로 갱신한다.

```
카드: [5, 6, 7, 8, 9], M=21

(i=0, j=1, z=2) -> 5+6+7 = 18 <= 21 -> MAX=18
(i=0, j=1, z=3) -> 5+6+8 = 19 <= 21 -> MAX=19
(i=0, j=1, z=4) -> 5+6+9 = 20 <= 21 -> MAX=20
(i=0, j=2, z=3) -> 5+7+8 = 20 <= 21 -> MAX=20 (변화 없음)
(i=0, j=2, z=4) -> 5+7+9 = 21 <= 21 -> MAX=21
...
최종 MAX = 21
```

## 코드 따라가기
```python
N, M = map(int, input().split())
```
첫째 줄에서 N과 M을 입력받는다. `map(int, ...)`은 공백으로 구분된 문자열을 정수로 변환한다.

```python
MAX = 0
arr = list(map(int, input().split()))
```
최대값을 저장할 변수 `MAX`를 0으로 초기화한다.
둘째 줄에서 카드 숫자들을 리스트 `arr`에 저장한다.

```python
for i in range(len(arr)):
    for j in range(i+1,len(arr)):
        for z in range(j+1,len(arr)):
```
3중 반복문으로 카드 3장을 고르는 모든 조합을 만든다.
- `i`: 첫 번째 카드 인덱스
- `j`: 두 번째 카드 인덱스 (`i`보다 큰 값부터 시작하여 중복 선택 방지)
- `z`: 세 번째 카드 인덱스 (`j`보다 큰 값부터 시작하여 중복 선택 방지)
이 구조는 조합(Combination)을 만드는 표준적인 방법이다. 순서가 중요하지 않고 같은 카드를 두 번 고르지 않는다.

```python
            if arr[i] + arr[j] + arr[z] <= M:
                MAX = max(MAX, arr[i] + arr[j] + arr[z])
```
현재 고른 3장의 카드 합이 `M` 이하인지 확인한다.
만약 조건을 만족하면, `max()` 함수를 사용하여 기존 `MAX`와 현재 합 중 더 큰 값을 `MAX`에 저장한다.
`max(a, b)`는 a와 b 중 큰 값을 반환한다.

```python
print(MAX)
```
모든 경우의 수를 확인한 후, 최종적으로 구한 최대 합 `MAX`를 출력한다.

## 외울 것
> **"N개 중 K개를 고르는 모든 경우의 수" → K중첩 for문 사용. 인덱스는 `range(i+1, ...)` 로 시작해 중복을 피한다.**
> **최댓값을 구할 때는 초기값을 0(또는 -무한대)으로 두고, 조건을 만족할 때마다 `max()`로 갱신한다.**
