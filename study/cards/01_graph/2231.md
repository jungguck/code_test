## 문제
자연수 N이 주어졌을 때, N의 **가장 작은 생성자**를 구하는 문제이다.
1. **분해합**: 어떤 자연수 M의 분해합은 `M + (M의 각 자리수의 합)`이다.
   - 예: 245의 분해합은 `245 + 2 + 4 + 5 = 256`
2. **생성자**: M의 분해합이 N이 되면, M을 N의 생성자라고 한다.
3. N의 생성자가 여러 개일 수 있으므로, 그중 **가장 작은 M**을 출력한다.
4. 생성자가 없으면 0을 출력한다.

## 입력
- 첫째 줄: 자연수 N (1 ≤ N ≤ 1,000,000)

## 출력
- 첫째 줄: N의 가장 작은 생성자 (없으면 0)

## 풀이 아이디어
**핵심 질문: "어떤 수 M을 더하면 N이 될까?"**
분해합의 정의에 따라 `M + digit_sum(M) = N`을 만족하는 M을 찾아야 한다.
N의 생성자 M은 N보다 작거나 같다. (M의 자리수 합은 M보다 작거나 같으므로, M + digit_sum(M) >= M)
실제로 M이 N보다 클 수는 없다. 왜냐하면 M >= 1이므로 digit_sum(M) >= 1이고, M + digit_sum(M) > M이기 때문이다.
하지만 M이 N보다 훨씬 작을 수도 있다.
예를 들어 N=100이면, M은 91(91+10=101? 아니 91+9+1=101), 90(90+9=99), 89(89+17=106)...
M은 N보다 작을 수 있지만, N보다 클 수는 없다.
또한 M은 1부터 N까지의 범위에서 찾을 수 있다.
가장 작은 생성자를 구해야 하므로, 1부터 N까지 순서대로 M을 검사하면서,
`M + digit_sum(M) == N`을 만족하는 첫 번째 M을 출력하면 된다.
만약 1부터 N까지 검사해도 만족하는 M이 없으면 0을 출력한다.

digit_sum(M)을 계산하는 방법은 M의 각 자리수를 추출해서 더하는 것이다.
`M % 10`으로 마지막 자리수를 추출하고, `M // 10`으로 마지막 자리수를 제거한 나머지를 구한다.
이 과정을 M이 0이 될 때까지 반복하면 모든 자리수의 합을 구할 수 있다.

## 코드 따라가기
```python
n = int(input())
```
입력받은 자연수 N을 정수로 변환하여 변수 `n`에 저장한다.

```python
def digist_sum(x):
    total = 0
    
    while x>0:
        total += x %10
        x = x // 10
        
    return total
```
`digist_sum(x)` 함수는 정수 `x`의 각 자리수의 합을 반환한다.
- `total = 0`: 합을 저장할 변수를 0으로 초기화한다.
- `while x > 0:`: `x`가 0보다 클 때까지 반복한다.
- `total += x % 10`: `x`의 마지막 자리수를 `total`에 더한다. `%`는 나머지 연산자이다.
- `x = x // 10`: `x`의 마지막 자리수를 제거한다. `//`는 정수 나눗셈 연산자이다.
- `return total`: 모든 자리수의 합을 반환한다.

```python
for x in range(1,n+1):
    if x+digist_sum(x) == n:
        print(x)
        break
else:
    print(0)
```
- `for x in range(1, n+1):`: 1부터 N까지의 모든 수 `x`를 순서대로 검사한다.
- `if x + digist_sum(x) == n:`: `x`의 분해합이 N과 같은지 확인한다.
- `print(x)`: 분해합이 N과 같으면, `x`가 N의 생성자이다. 가장 작은 생성자를 구해야 하므로, 처음으로 찾은 `x`를 출력한다.
- `break`: 가장 작은 생성자를 찾았으므로, 더 이상 검사할 필요가 없으므로 반복문을 종료한다.
- `else: print(0)`: `for` 루프가 `break`로 종료되지 않고 정상적으로 끝났을 때(생성자를 찾지 못한 경우) 실행된다. 생성자가 없으므로 0을 출력한다.
  - **주의**: 파이썬의 `for ... else` 문법은 `for` 루프가 `break`로 중단되지 않고 끝까지 실행되면 `else` 블록이 실행된다. `break`가 실행되면 `else` 블록은 실행되지 않는다.

## 외울 것
> **"분해합" 문제 → `M + digit_sum(M) = N` → 1부터 N까지 순서대로 M을 검사 → 첫 번째로 만족하는 M이 답.**
> `for ... else`는 `break`가 없으면 `else`가 실행된다.
