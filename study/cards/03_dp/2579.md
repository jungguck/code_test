## 문제
계단이 N개 있고, 각 계단마다 점수가 적혀 있다.
바닥에서 출발해 꼭대기까지 올라가면서 **밟은 계단의 점수를 모두 더한다.**

규칙이 세 가지다.
1. 한 번에 **1칸 또는 2칸**만 오를 수 있다
2. **연속된 세 계단을 모두 밟으면 안 된다** (출발점인 바닥은 계단이 아니다)
3. **마지막 계단은 반드시 밟아야 한다**

얻을 수 있는 점수의 최댓값을 구하라.

## 입력
- 첫째 줄: N (1 ≤ N ≤ 300)
- 다음 N줄: 각 계단의 점수 (10,000 이하의 자연수)

## 출력
- 최대 점수 하나

## 예제
```
입력          출력
6             75
10
20
15
25
10
20
```
`10 + 20 + 25 + 20 = 75` — 3번(15)과 5번(10) 계단을 건너뛴다.

## 풀이 아이디어

**이 문제의 핵심 질문: "i번째 계단을 밟았다면, 직전 계단도 밟았나?"**

규칙 2 때문에 "직전을 밟았는지"에 따라 경우가 갈린다. 그래서 이렇게 정의한다.

> `dp[i]` = **i번째 계단을 밟았을 때** 얻을 수 있는 최대 점수

i번째 계단에 도착하는 방법은 딱 두 가지뿐이다.

```
① 2칸 점프해서 왔다          → i-1 은 안 밟았다
   . . ■ . ■                dp[i] = dp[i-2] + 점수[i]
        i-2   i

② 1칸 올라서 왔다            → i-1 을 밟았다
   그럼 i-2 는 밟으면 안 된다 (i-2, i-1, i 세 개 연속이 되니까)
   → i-3 에서 i-1 로 점프해 온 것
   . ■ . ■ ■                dp[i] = dp[i-3] + 점수[i-1] + 점수[i]
     i-3   i-1 i
```

둘 중 큰 쪽이 답이다.

```
dp[i] = max( dp[i-2] , dp[i-3] + 점수[i-1] ) + 점수[i]
```

## 코드 따라가기

```python
dp = [lst[0], lst[0]+lst[1], max(lst[0], lst[1])+lst[2]]
```
i가 3보다 작으면 `dp[i-3]` 이 음수 인덱스가 되어 엉뚱한 값을 읽는다.
그래서 **앞의 세 칸은 손으로 직접 채워넣는다.**
- `dp[0]` = 첫 계단만 밟음
- `dp[1]` = 두 계단 다 밟음 (두 개는 연속해도 됨)
- `dp[2]` = 1번이나 2번 중 큰 것 + 3번 (세 개 다 밟으면 규칙 위반)

```python
next_max = max(dp[i-2], dp[i-3]+lst[i-1])
dp.append(next_max + lst[i])
```
위에서 세운 점화식 그대로다. `lst[i]` 는 마지막에 한 번만 더한다.

```python
print(dp[-1])
```
규칙 3 때문에 **마지막 계단은 반드시 밟는다.** 그래서 `max(dp)` 가 아니라 `dp[-1]` 이다.
이걸 `max(dp)` 로 쓰면 틀린다.

## ⚠️ 이 코드의 버그
```python
if n > 3:      # ← n == 3 일 때 else 로 빠진다
    ...
else:
    print(sum(lst))
```
N이 정확히 3이면 `sum(전부)` 를 출력하는데, 그건 **세 계단을 연속으로 다 밟는 것**이라 규칙 위반이다.
```
입력 3 / 10 / 20 / 15  →  이 코드: 45   정답: max(10,20)+15 = 35
```
고치려면 `n > 3` 을 `n >= 3` 으로 바꾸고 `dp` 초기 3칸만 만든 뒤 `dp[-1]` 을 출력하면 된다.
(백준 채점 데이터에 N=3이 없어서 통과한 것으로 보인다)

## 외울 것
> **"연속 3개 금지" → 직전을 밟았는지로 경우를 가른다 → `dp[i-2]` vs `dp[i-3] + 전칸`**
>
> 마지막을 반드시 밟아야 하면 답은 `max(dp)` 가 아니라 **`dp[-1]`**
