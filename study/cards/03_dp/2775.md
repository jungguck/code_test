## 문제
아파트의 각 층과 호수에 거주하는 사람의 수를 구하는 문제이다.
아파트는 0층부터 시작하며, 각 층에는 1호부터 n호까지 있다.
거주 규칙은 다음과 같다:
1. 0층의 i호에는 i명이 산다. (예: 0층 1호=1명, 0층 2호=2명, ...)
2. a층의 b호에 살려면, 자신의 아래층(a-1층)의 1호부터 b호까지 사람들의 수의 합만큼 사람들을 데려와야 한다.
   즉, `a층 b호의 인원 = (a-1층 1호 + a-1층 2호 + ... + a-1층 b호)`
3. 주어지는 k층 n호에 사는 사람의 수를 출력한다.

## 입력
- 첫째 줄: 테스트 케이스의 수 T
- 각 테스트 케이스마다:
  - 첫째 줄: 정수 k (층 수)
  - 둘째 줄: 정수 n (호수)

<!-- 확인필요: k, n의 최대 범위를 코드만으로는 알 수 없음 -->

## 출력
- 각 테스트 케이스에 대해, k층 n호에 거주하는 사람의 수를 한 줄씩 출력한다.

## 풀이 아이디어
**핵심 질문: "a층 b호의 인원은 어떻게 결정되는가?"**
문제 설명에 따르면, `a층 b호`의 인원은 `(a-1)층`의 `1호 ~ b호` 인원의 합입니다.
이것을 직접 계산하려면 매번 1호부터 b호까지 더해야 해서 시간이 오래 걸립니다.
하지만 **DP(다이나믹 프로그래밍)**를 사용하면 이전에 계산한 값을 재사용할 수 있습니다.

`dp[i][j]` = i층 j호에 사는 사람의 수

**점화식 유도:**
`dp[i][j]`는 `(i-1)층`의 `1호 ~ j호`의 합입니다.
이 합은 `(i-1)층`의 `1호 ~ (j-1)호`의 합에 `(i-1)층 j호`를 더한 것과 같습니다.
즉, `dp[i][j] = (dp[i-1][1] + ... + dp[i-1][j-1]) + dp[i-1][j]`

여기서 `(dp[i-1][1] + ... + dp[i-1][j-1])`은 무엇일까요?
이것은 `i층 (j-1)호`의 인원, 즉 `dp[i][j-1]`와 같습니다.
(왜냐하면 `dp[i][j-1]`는 `(i-1)층`의 `1호 ~ (j-1)호`의 합이기 때문입니다.)

따라서 최종 점화식은 다음과 같습니다:
```
dp[i][j] = dp[i][j-1] + dp[i-1][j]
```
- `dp[i][j-1]`: 같은 층(i층)의 왼쪽 호(j-1호)의 인원 (이 값에는 아래층 1~j-1호의 합이 포함되어 있음)
- `dp[i-1][j]`: 바로 아래층(i-1층)의 같은 호(j호)의 인원

**초기값:**
0층은 규칙이 다르므로 따로 설정합니다.
`dp[0][j] = j` (0층 j호에는 j명)

## 코드 따라가기

```python
t = int(input())
```
- 테스트 케이스의 개수 T를 입력받습니다.

```python
for _ in range(t):
    k = int(input())
    n = int(input())
```
- T번 반복합니다.
- 각 케이스마다 층 수 `k`와 호 수 `n`을 입력받습니다.
- `for _ in range(t)`에서 `_`는 반복 횟수를 세는 변수를 무시할 때 사용하는 관례입니다.

```python
    dp = [[0] * (n + 1) for _ in range(k + 1)]
```
- **2차원 리스트(행렬) 생성**입니다.
- `range(k + 1)`: 0층부터 k층까지, 총 k+1개의 행(층)을 만듭니다.
- `[0] * (n + 1)`: 각 행에 0호부터 n호까지, 총 n+1개의 열(호)을 0으로 채웁니다.
- `dp[i][j]`는 i층 j호를 의미합니다. 인덱스 0을 0층/0호로 사용하기 위해 크기를 +1로 잡습니다.

```python
    # 0층 초기화
    for i in range(1, n + 1):
        dp[0][i] = i
```
- 0층의 인원은 호수 그대로입니다.
- `dp[0][1] = 1`, `dp[0][2] = 2`, ..., `dp[0][n] = n`으로 설정합니다.
- `dp[0][0]`은 0으로 두어 계산 편의를 돕습니다.

```python
    # 채우기
    for i in range(1, k + 1):
        for j in range(1, n + 1):
            dp[i][j] = dp[i][j-1] + dp[i-1][j]
```
- 1층부터 k층까지, 1호부터 n호까지 점화식을 적용합니다.
- `dp[i][j]` (현재 위치) = `dp[i][j-1]` (왼쪽 이웃) + `dp[i-1][j]` (아래 이웃)
- 이 순서로 채워나가면 필요한 값들이 이미 계산되어 있어 효율적입니다.

```python
    print(dp[k][n])
```
- 최종적으로 k층 n호의 인원 `dp[k][n]`을 출력합니다.

## 외울 것
> **"현재 값 = 왼쪽 값 + 아래 값"**
> 2차원 DP에서 누적합이나 누적된 영향을 받는 경우, `dp[i][j] = dp[i][j-1] + dp[i-1][j]` 패턴을 기억하세요.
> 0행(또는 0열)은 초기값이 다르므로 반드시 따로 설정해야 합니다.
