# G03. 부품 고르기 ⭐⭐ (완전탐색 / 백트래킹)

창고에 부품 N개가 있고, 각각 무게가 정해져 있다.

이 중에서 **정확히 K개**를 골라 상자에 담으려 한다.
상자는 무게 **M까지** 버틴다.

담을 수 있는 경우 중 **무게 합이 가장 큰 값**을 구하라.
K개를 골라도 항상 M을 넘는다면 `-1` 을 출력한다.

## 입력
- 첫째 줄: N K M  (1 ≤ K ≤ N ≤ 15, 1 ≤ M ≤ 100,000)
- 둘째 줄: N개의 부품 무게  (1 ≤ 무게 ≤ 10,000)

## 출력
- 가능한 최대 무게 합. 불가능하면 -1

## 예제 입력
```
5 3 21
5 6 7 8 9
```

## 예제 출력
```
21
```

### 왜 21인가
3개를 고르는 모든 경우 중 합이 21 이하인 것들:
```
5+6+7 = 18
5+6+8 = 19
5+6+9 = 20
5+7+8 = 20
5+7+9 = 21   ← 딱 21. 이보다 큰 건 전부 21을 넘는다
5+8+9 = 22   ✗
6+7+8 = 21   ← 이것도 21
...
```

## 힌트
- N이 최대 15라 모든 조합을 다 만들어봐도 된다 (최대 32,768가지)
- **고른다 / 안 고른다** 를 재귀로 갈라가며 만드는 게 백트래킹이다
