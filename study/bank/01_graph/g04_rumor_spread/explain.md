# 답지 — G04. 소문 퍼지기

## 핵심 아이디어
G02(미로)와 **똑같은 BFS** 다. 다른 건 딱 하나, **판이 격자가 아니라 그래프**라는 것.

| | 미로 | 소문 |
|---|---|---|
| 한 칸 | `(x, y)` 좌표 | 사람 번호 `1 ~ N` |
| 옆으로 갈 곳 | 상하좌우 4방향 | `adj[사람]` 에 적힌 아는 사람들 |
| 거리 | 지나온 칸 수 | 소문 들은 날짜 |

**"다음에 갈 곳을 어떻게 찾느냐"만 바뀌고 BFS 뼈대는 그대로다.** 이걸 알면 그래프 문제 절반이 풀린다.

## 인접 리스트가 뭔가
"누가 누구를 아는지" 를 저장하는 방법이다.

```
입력                  adj (인접 리스트)
1 2                   adj[1] = [2, 3]      1번은 2번, 3번을 안다
1 3                   adj[2] = [1, 4]      2번은 1번, 4번을 안다
2 4                   adj[3] = [1]
4 5                   adj[4] = [2, 5]
                      adj[5] = [4]
```

```python
adj[a].append(b)
adj[b].append(a)   # ← 이 줄을 빼먹는 실수가 제일 흔하다
```
"아는 사이"는 양방향이므로 **양쪽에 다 넣어야 한다.**
한쪽만 넣으면 단방향(일방통행)이 되어 답이 틀린다.

## 초보가 막히는 곳

**① `range(n + 1)` 인 이유**
사람 번호가 1번부터 N번까지다. `adj[N]` 을 쓰려면 리스트 길이가 N+1이어야 한다.
`adj[0]` 은 안 쓰고 버린다. 번호를 그대로 인덱스로 쓰려고 일부러 한 칸 낭비하는 것.

**② `[[] for _ in range(n+1)]` vs `[[]] * (n+1)`**
```python
adj = [[]] * 5        # ❌ 빈 리스트 "하나"를 5번 가리킴. adj[0].append 하면 전부 바뀐다
adj = [[] for _ in range(5)]   # ✅ 서로 다른 빈 리스트 5개
```
이건 파이썬 초보가 거의 다 한 번은 당하는 함정이다.

**③ `day[1] = 0` 인 이유**
1번은 소문을 퍼뜨린 사람이라 "0일차에 이미 알고 있다". 그래서 답을 셀 때는 2번부터 센다.

**④ 아무도 못 듣는 경우**
`heard` 가 빈 리스트면 `max()` 가 에러를 낸다. 그래서 `if not heard:` 로 먼저 걸러야 한다.

## 시간복잡도
O(N + M) — 사람 한 명당 한 번, 관계 하나당 한 번씩만 본다.
