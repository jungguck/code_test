# G04. 소문 퍼지기 ⭐⭐ (그래프 탐색 / BFS)

공장에 직원 N명이 있고, 번호는 1번부터 N번까지다.
어떤 두 사람은 서로 **아는 사이**다. (아는 사이는 양쪽 다 성립한다)

**1번 직원**이 소문을 하나 퍼뜨렸다.
소문은 하루에 한 단계씩, 아는 사람에게 전부 퍼진다.

- 1일차: 1번과 직접 아는 사람들이 듣는다
- 2일차: 그 사람들이 아는 사람들이 듣는다
- …

두 가지를 구하라.
1. 소문을 **듣게 되는 사람 수** (1번 본인은 빼고 센다)
2. **가장 늦게 듣는 사람**이 듣기까지 걸리는 **날짜**

아무도 못 들으면 `0 0` 을 출력한다.

## 입력
- 첫째 줄: N M  (1 ≤ N ≤ 1,000, 0 ≤ M ≤ 10,000)
- 다음 M줄: 두 정수 a b — a와 b가 아는 사이

## 출력
- 듣는 사람 수와 날짜를 공백으로 구분해 한 줄에 출력

## 예제 입력
```
5 4
1 2
1 3
2 4
4 5
```

## 예제 출력
```
4 3
```

### 왜 4명, 3일인가
```
        1              0일차 (소문 시작)
       / \
      2   3            1일차 — 2번, 3번이 듣는다
      |
      4                2일차 — 4번이 듣는다
      |
      5                3일차 — 5번이 듣는다

듣는 사람: 2, 3, 4, 5 → 4명
가장 늦게 듣는 사람: 5번 → 3일
```

## 힌트
- 격자가 아니라 **사람과 사람** 을 잇는 그래프다. 인접 리스트로 저장한다
- 날짜 = 1번으로부터의 거리. BFS 로 거리를 재면 그대로 답이다
