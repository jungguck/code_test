# 답지 — G02. 최단 경로

## 핵심 아이디어
**최단거리는 BFS.** 이건 외워도 된다.

BFS 는 출발점에서 **1칸 거리 전부 → 2칸 거리 전부 → 3칸 거리 전부** 순서로 퍼진다.
그래서 어떤 칸에 **처음 도착했을 때가 곧 그 칸까지의 최단거리**다.
나중에 다른 길로 또 닿아도 그건 더 길거나 같은 길이라 볼 필요가 없다.

DFS 는 한 방향으로 끝까지 파고들기 때문에 먼저 도착해도 그게 최단이라는 보장이 없다.

## 코드가 하는 일
```
dist[0][0] = 1        출발 칸. "지나간 칸 수" 를 세므로 0이 아니라 1
큐에서 칸을 꺼낸다
  네 방향을 본다
    판 밖 / 벽 / 이미 가본 칸 → 건너뛴다
    처음 보는 칸 → dist[새칸] = dist[지금칸] + 1  하고 큐에 넣는다
큐가 빌 때까지 반복
마지막에 dist[N-1][M-1] 을 출력
```

## 초보가 막히는 곳

**① `visited` 대신 `dist` 하나로 끝낸 이유**
`dist[nx][ny] != 0` 이면 이미 와본 칸이다. 거리를 적는 순간 방문 표시도 된 셈이라
배열 두 개를 만들 필요가 없다.

**② 왜 큐에 넣을 때 거리를 적나?**
꺼낼 때 적으면 같은 칸이 큐에 여러 번 들어가서 거리가 덮어써진다.
**넣는 순간 적고 넣는다** — 이게 BFS 의 기본 규칙이다.

**③ 도착 못 하는 경우**
끝까지 돌았는데 `dist[N-1][M-1]` 이 그대로 0이면 한 번도 못 닿은 것이다. 그래서 -1.

**④ 출발 칸이 1이 아니라 0이면?**
이 문제는 "출발 칸은 항상 1" 이라고 못박았다. 실제 문제에서는 이런 조건을 꼭 확인해야 한다.

## BFS vs DFS 언제 뭘 쓰나
| 묻는 것 | 쓰는 것 |
|---|---|
| **최단** 거리 / 최소 횟수 | **BFS** |
| 덩어리 개수, 다 돌기만 하면 될 때 | 둘 다 OK |
| 모든 경우를 만들어봐야 할 때 (조합/순열) | **DFS(백트래킹)** |

## 시간복잡도
O(N×M) — 칸마다 한 번씩만 큐에 들어간다.
