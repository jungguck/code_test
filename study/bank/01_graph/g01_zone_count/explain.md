# 답지 — G01. 구역 세기

## 핵심 아이디어
격자에서 **"붙어있는 덩어리 개수 세기"** 는 BFS/DFS의 가장 기본 형태다.

> 1을 하나 발견하면 → 거기서 출발해 **붙어있는 1을 전부 지운다** → 덩어리 1개 완성

지우면서 퍼지기 때문에, 한 덩어리는 딱 한 번만 세어진다.

## 코드가 하는 일
```
격자를 왼쪽 위부터 한 칸씩 훑는다
  1을 만났다? → count += 1  (새 덩어리 발견)
                 그 자리에서 BFS 시작
                 큐에서 칸을 하나 꺼내
                   상하좌우 네 방향을 본다
                     판 밖이면 무시
                     0이면 무시
                     1이면 → 0으로 지우고 큐에 넣는다
                 큐가 빌 때까지 반복 = 덩어리 하나 다 지움
```

## 초보가 막히는 곳

**① `visited` 배열이 왜 없나?**
보통은 방문 표시용 배열을 따로 만든다. 여기서는 **1을 0으로 덮어써서** 그 역할을 대신했다.
이미 0이 된 칸은 다시 안 세니까 방문 표시와 똑같다. 배열 하나를 아낀 것.

**② `dx`, `dy` 는 뭔가?**
네 방향을 일일이 쓰면 `if` 가 네 번 나온다. 그래서 방향을 배열로 만들어 `for` 한 번으로 돈다.
```
dx = [-1, 1, 0, 0]      dx[0], dy[0] = (-1,  0) → 위
dy = [ 0, 0,-1, 1]      dx[1], dy[1] = ( 1,  0) → 아래
                        dx[2], dy[2] = ( 0, -1) → 왼쪽
                        dx[3], dy[3] = ( 0,  1) → 오른쪽
```

**③ 큐에 넣을 때 바로 지워야 한다**
큐에 넣어놓고 나중에 꺼낼 때 지우면, 그 사이에 같은 칸이 큐에 여러 번 들어간다.
**넣는 순간 지우는 것**이 정석이다.

**④ `deque` 를 왜 쓰나?**
리스트로도 큐를 만들 수 있지만 `list.pop(0)` 은 앞을 빼낼 때마다 뒤 원소를 전부 한 칸씩 당긴다 → 느리다.
`deque.popleft()` 는 그냥 앞을 뗀다 → 빠르다.

## 시간복잡도
O(N×M) — 모든 칸을 많아야 한 번씩만 본다. 100×100이면 1만 칸, 순식간.
