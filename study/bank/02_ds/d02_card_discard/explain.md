# 답지 — D02. 카드 버리기

## 핵심 아이디어
문제 설명을 **그대로** 코드로 옮기면 끝난다. 머리 쓸 게 없다.
중요한 건 **어떤 자료구조를 쓰느냐**다.

- "맨 위에서 뺀다" → 앞에서 빼기
- "맨 아래로 넣는다" → 뒤에 넣기

앞에서 빼고 뒤에 넣는 것 = **큐(queue)**. 파이썬에서는 `deque` 를 쓴다.

## 코드 세 줄이 전부다
```python
cards.popleft()                  # ① 맨 위를 버린다
cards.append(cards.popleft())    # ② 다음 것을 빼서(popleft) 뒤에 붙인다(append)
```

②는 한 줄에 두 가지를 한다. 풀어 쓰면 이렇다:
```python
moved = cards.popleft()   # 다음 카드를 꺼내고
cards.append(moved)       # 맨 아래에 붙인다
```

## 초보가 막히는 곳

**① `deque` 를 왜 쓰나 — 리스트면 안 되나?**
```python
cards = [1, 2, 3, 4, 5]
cards.pop(0)     # 1을 빼면 2,3,4,5 를 전부 한 칸씩 앞으로 당긴다
```
카드가 50만 장이면 한 번 뺄 때마다 50만 번 당긴다 → 전체 O(N²) → **시간초과**.

`deque` 는 **앞뒤 양끝을 바로 처리하도록 만들어진 자료구조**라 당기는 작업이 없다.

| | 리스트 | deque |
|---|---|---|
| 뒤에 넣기 | `append` 빠름 | `append` 빠름 |
| **앞에서 빼기** | `pop(0)` **느림 O(N)** | `popleft()` **빠름 O(1)** |

**② `deque(range(1, n+1))`**
`range(1, n+1)` 은 1부터 n까지의 숫자를 만든다. (n+1은 포함 안 됨 — 파이썬의 기본 규칙)
그걸 통째로 `deque` 에 담은 것이다.

**③ `while len(cards) > 1` — 왜 0이 아니라 1인가?**
"한 장 남을 때까지" 반복이므로, **두 장 이상일 때만** 돈다.
`> 0` 으로 쓰면 마지막 한 장까지 버려서 `cards[0]` 에서 에러가 난다.

**④ N=1 인 경우**
카드가 한 장이면 `while` 이 한 번도 안 돈다. 그대로 1이 출력된다. 이게 맞는 답이다.
이렇게 **"반복문이 아예 안 도는 경우"** 를 항상 확인하는 습관을 들이면 실수가 줄어든다.

## 시간복잡도
O(N) — 카드 한 장당 버려지거나 옮겨지는 횟수가 정해져 있다.
