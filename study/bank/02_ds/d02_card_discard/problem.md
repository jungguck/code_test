# D02. 카드 버리기 ⭐ (자료구조 / 큐)

1번부터 N번까지 번호가 적힌 카드가 **위에서부터 1, 2, 3 … N 순서로** 쌓여 있다.

다음을 카드가 한 장 남을 때까지 반복한다.
1. 맨 **위** 카드를 버린다
2. 그 다음 맨 위 카드를 **맨 아래로** 옮긴다

마지막에 남는 카드의 번호를 구하라.

## 입력
- 첫째 줄: N  (1 ≤ N ≤ 500,000)

## 출력
- 마지막에 남는 카드 번호

## 예제 입력
```
6
```

## 예제 출력
```
4
```

### 손으로 따라가기
```
[1 2 3 4 5 6]   1을 버린다 → [2 3 4 5 6]   2를 아래로 → [3 4 5 6 2]
[3 4 5 6 2]     3을 버린다 → [4 5 6 2]     4를 아래로 → [5 6 2 4]
[5 6 2 4]       5를 버린다 → [6 2 4]       6을 아래로 → [2 4 6]
[2 4 6]         2를 버린다 → [4 6]         4를 아래로 → [6 4]
[6 4]           6을 버린다 → [4]           한 장 남았다
                                            답: 4
```

## 힌트
- 앞에서 빼고 뒤에 넣는 동작 = **큐(queue)**
- 리스트의 `pop(0)` 은 앞을 뺄 때마다 나머지를 전부 한 칸씩 당겨서 느리다.
  `deque` 를 쓰면 앞뒤 모두 즉시 처리된다
