# D04. 부품 재고 ⭐ (자료구조 / 해시)

창고에 부품이 N개 들어와 있다. 같은 이름의 부품이 여러 개 있을 수 있다.

그 다음 M개의 부품 이름을 물어본다.
각 이름이 창고에 **몇 개** 있는지 출력하라. 하나도 없으면 `0` 이다.

## 입력
- 첫째 줄: N  (1 ≤ N ≤ 500,000)
- 둘째 줄: N개의 부품 이름, 공백으로 구분 (영소문자, 길이 1~20)
- 셋째 줄: M  (1 ≤ M ≤ 500,000)
- 넷째 줄: M개의 물어볼 이름, 공백으로 구분

## 출력
- M개의 답을 공백으로 구분해 한 줄에 출력

## 예제 입력
```
5
bolt nut bolt washer bolt
3
bolt nut screw
```

## 예제 출력
```
3 1 0
```

### 왜 이렇게 되나
```
창고:  bolt ×3, nut ×1, washer ×1
bolt   → 3개
nut    → 1개
screw  → 창고에 없다 → 0
```

## 핵심 함정 ⚠️
리스트에 담고 `parts.count(이름)` 으로 세면, 한 번 셀 때마다 **N개를 전부 훑는다.**
M번 물어보면 O(N×M) = 50만 × 50만 = **2500억 번** → 절대 못 끝난다.

**dict(해시)** 를 쓰면 한 번 세어두고 조회는 O(1) 이다.

## 힌트
- 이름을 키, 개수를 값으로 하는 `dict` 를 만든다
- 없는 키를 조회하면 에러가 난다. `dict.get(키, 0)` 을 쓰면 없을 때 0을 돌려준다
