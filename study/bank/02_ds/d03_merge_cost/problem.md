# D03. 자재 합치기 ⭐⭐ (자료구조 / 우선순위 큐)

창고에 자재 묶음이 N개 있고, 각 묶음의 무게가 주어진다.

두 묶음을 **하나로 합칠 때** 드는 비용은 **두 묶음 무게의 합**이다.
합친 묶음은 그 무게를 가진 새 묶음이 된다.

모든 묶음을 하나로 합칠 때, **비용의 합이 가장 작아지는 값**을 구하라.

## 입력
- 첫째 줄: N  (1 ≤ N ≤ 100,000)
- 다음 N줄: 각 묶음의 무게  (1 ≤ 무게 ≤ 1,000)

## 출력
- 최소 비용의 합

## 예제 입력
```
4
10
20
40
50
```

## 예제 출력
```
220
```

### 왜 220인가
**항상 가벼운 것 두 개를 먼저 합치면** 된다.
```
[10, 20, 40, 50]   10 + 20 = 30   비용 30
[30, 40, 50]       30 + 40 = 70   비용 70
[70, 50]           70 + 50 = 120  비용 120
                                  합계 220
```

무거운 것부터 합치면 이렇게 손해다:
```
[10, 20, 40, 50]   50 + 40 = 90   비용 90
[90, 10, 20]       90 + 20 = 110  비용 110
[110, 10]          110 + 10 = 120 비용 120
                                  합계 320   ← 220보다 크다
```

## 왜 가벼운 것부터인가 ⚠️
먼저 합친 묶음은 **그 다음에도 계속 다시 더해진다.**
일찍 합쳐질수록 여러 번 세어지므로, **가벼운 것을 먼저** 합쳐야 손해가 적다.

## 힌트
- 매번 "가장 가벼운 두 개" 를 꺼내야 한다
- 매번 정렬하면 O(N² log N) 으로 느리다. **우선순위 큐(heapq)** 를 쓰면 꺼내는 데 O(log N)
