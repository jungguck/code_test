# 답지 — D03. 자재 합치기

## 핵심 아이디어
**"매번 가장 가벼운 두 개를 합친다."** 이 한 줄이 전부다.

왜 그런가? 먼저 합쳐진 묶음은 **그 뒤로도 계속 다시 더해지기 때문**이다.
```
10과 20을 먼저 합치면 → 30
그 30이 다음에 또 더해지고, 그 다음에도 또 더해진다
→ 일찍 합칠수록 "여러 번 세어진다"
→ 그러니 여러 번 세어질 애는 가벼울수록 이득
```

## 우선순위 큐(heap)가 뭔가
**"넣는 건 아무렇게나, 꺼낼 땐 항상 제일 작은 것"** 을 해주는 자료구조다.

| 하는 일 | 리스트로 | heap 으로 |
|---|---|---|
| 넣기 | `append` O(1) | `heappush` O(log N) |
| **제일 작은 것 꺼내기** | 전부 훑어야 함 **O(N)** | `heappop` **O(log N)** |

매번 `min()` 으로 찾거나 매번 `sort()` 하면 느리다. heap 은 내부를 항상 반쯤 정렬된 상태로
유지해서, 최솟값을 빠르게 내준다.

## 코드가 하는 일
```python
while len(heap) > 1:            # 묶음이 2개 이상 남아있는 동안
    a = heapq.heappop(heap)     # 제일 가벼운 것
    b = heapq.heappop(heap)     # 그 다음 가벼운 것
    total += a + b              # 합치는 비용을 더하고
    heapq.heappush(heap, a + b) # 합쳐진 묶음을 다시 집어넣는다
```
합친 묶음을 **다시 넣는 것**이 핵심이다. 그 묶음도 나중에 또 합쳐질 대상이기 때문.

## 초보가 막히는 곳

**① `import heapq` — 리스트를 그냥 쓴다**
파이썬의 heap 은 별도 타입이 아니라 **그냥 리스트**다. `heapq` 함수들을 통해서만 건드리면
그 리스트가 heap 규칙을 유지한다.
```python
heap = []                       # 그냥 빈 리스트
heapq.heappush(heap, 5)         # heapq 함수로 넣고
x = heapq.heappop(heap)         # heapq 함수로 뺀다
heap.append(3)                  # ❌ 이러면 규칙이 깨진다
```

**② `heap[0]` 은 최솟값이 맞지만 `heap[1]` 은 두 번째가 아니다**
heap 은 완전히 정렬된 게 아니라 "맨 앞이 최솟값"만 보장한다. 중간을 직접 읽으면 안 된다.

**③ N=1 이면 답이 0**
묶음이 하나면 합칠 게 없다 → 비용 0. `while` 이 한 번도 안 돌아서 자동으로 0이 나온다.

**④ 큰 값부터 꺼내고 싶으면?**
파이썬 heapq 는 최소 힙만 있다. 최대가 필요하면 **부호를 뒤집어서** 넣는다.
```python
heapq.heappush(heap, -x)        # 넣을 때 마이너스
big = -heapq.heappop(heap)      # 뺄 때 다시 마이너스
```

## 시간복잡도
O(N log N) — N번 합치고, 매번 heap 조작이 log N.
