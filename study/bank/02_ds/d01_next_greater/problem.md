# D01. 다음 큰 수 ⭐⭐⭐ (자료구조 / 스택)

길이 N인 수열이 있다.

각 원소마다 **자기보다 오른쪽에 있으면서, 자기보다 큰 수 중 가장 왼쪽 것**을 찾아라.
그런 수가 없으면 `-1` 이다.

## 입력
- 첫째 줄: N  (1 ≤ N ≤ 1,000,000)
- 둘째 줄: N개의 정수  (1 ≤ 값 ≤ 1,000,000)

## 출력
- N개의 답을 공백으로 구분해 한 줄에 출력

## 예제 입력
```
4
3 5 2 7
```

## 예제 출력
```
5 7 7 -1
```

### 왜 이렇게 되나
```
3 → 오른쪽에 5, 2, 7.  처음 만나는 더 큰 수는 5
5 → 오른쪽에 2, 7.     2는 작다. 7이 답
2 → 오른쪽에 7.        7이 답
7 → 오른쪽에 아무것도 없다 → -1
```

## 핵심 함정 ⚠️
"각 원소마다 오른쪽을 끝까지 훑는다" 로 짜면 **O(N²)** 이다.
N이 100만이면 1조 번 비교 → 절대 시간 안에 안 끝난다.

**스택을 쓰면 O(N)** 에 끝난다. 각 원소가 스택에 딱 한 번 들어갔다 한 번 나오기 때문이다.

## 힌트
- 답을 아직 못 찾은 원소들을 스택에 쌓아둔다
- 새 수가 들어올 때, 스택 위에 있는 수들 중 **새 수보다 작은 것들은 답이 지금 정해진다**
