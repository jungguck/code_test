## 하는 법

1. 위 분류에서 하나 골라 들어간다 (난이도순으로 정렬돼 있음)
2. 맨 위 안 푼 문제(⬜)의 번호를 눌러 백준으로 간다
3. 백준에서 풀고 제출한다 → BaekjoonHub 확장이 자동으로 커밋해준다
4. 체크 갱신:

   ```
   git pull
   python study/progress.py
   git add -A && git commit -m "progress" && git push
   ```
