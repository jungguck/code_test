# hard02 파이썬 문법 노트 🐍

> 공통 문법은 [`SYNTAX.md`](../SYNTAX.md) 참고.

## 이 문제에 나오는 문법

### 1. `%` (나머지)와 음수

```python
s = (s + x) % m
```

`%` 는 나눈 나머지다. 파이썬의 `%` 는 **결과 부호가 오른쪽 값을 따른다**는 게 특징.

```python
 7 % 3      #  1
-7 % 3      #  2   ← C/Java 는 -1 이 나온다!
```

파이썬에서는 음수를 넣어도 결과가 **항상 0 이상 m 미만**이라 카운팅 배열의 인덱스로
바로 써도 안전하다. (다른 언어로 옮길 땐 `((x % m) + m) % m` 이 필요하다)

### 2. `//` (정수 나눗셈)

```python
total += c * (c - 1) // 2
```

`/` 는 **항상 실수**를 준다. 큰 수에서 오차가 생기므로 정수 계산엔 `//` 를 쓴다.

```python
7 / 2        # 3.5   (float)
7 // 2       # 3     (int)
10**18 / 2   # 5e+17  ← 정밀도가 깨진다
10**18 // 2  # 500000000000000000  ✓
```

`c * (c - 1)` 은 연속한 두 정수의 곱이라 **항상 짝수**다. 그래서 `// 2` 로 나눠도
버려지는 게 없다. 연산 순서상 곱셈이 먼저, 나눗셈이 나중인 것도 중요하다
(`c * ((c-1) // 2)` 로 쓰면 홀수일 때 틀린다).

### 3. 카운팅 배열 `[0] * m`

```python
cnt = [0] * m
cnt[0] = 1
...
cnt[s] += 1
```

**값 자체를 인덱스로 쓰는** 자료구조. 딕셔너리보다 훨씬 빠르다.

쓸 수 있는 조건: 값의 범위가 **작고**, **0 이상**이어야 한다.
여기선 `% m` 을 거쳐서 0 ~ m-1 (최대 1000)로 눌러놨기 때문에 가능하다.

범위가 크거나 음수가 섞이면 딕셔너리를 쓴다.
```python
from collections import defaultdict
cnt = defaultdict(int)      # 없는 키를 읽으면 자동으로 0
cnt[s] += 1                 # KeyError 가 안 난다
```

1차원 `[0] * m` 은 숫자가 불변이라 안전하다. **2차원부터는 컴프리헨션을 써야 한다**
([q04 노트](../q04_clean_zone/syntax.md) 1번 참고).

### 4. 누적 변수를 루프 밖에서 초기화

```python
s = 0
for x in a:
    s = (s + x) % m
    cnt[s] += 1
```

`s` 를 루프 **밖**에서 0으로 두는 게 곧 `P[0] = 0` 이다.
그리고 `cnt[0] = 1` 이 그 `P[0]` 을 세어주는 한 줄.

이 두 줄의 관계를 못 보면 답이 조용히 작게 나온다. **"빈 접두사도 접두사다"** 가 이 문제의 전부.

### 5. `sum()` 과 제너레이터 표현식

풀이는 for 문으로 더하지만, 한 줄로도 쓸 수 있다.

```python
total = sum(c * (c - 1) // 2 for c in cnt)
```

`sum(...)` 안의 `c * ... for c in cnt` 는 **제너레이터 표현식** — 리스트를 만들지 않고
값을 하나씩 흘려보낸다. 대괄호를 쓴 `sum([... for c in cnt])` 는 리스트를 통째로
만들었다가 버려서 메모리를 더 쓴다.

```python
sum(x for x in a)       # ✓ 제너레이터 — 메모리 O(1)
sum([x for x in a])     # 리스트를 먼저 다 만든다 — 메모리 O(N)
```
