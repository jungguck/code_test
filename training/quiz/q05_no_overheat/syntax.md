## 이 문제에 나오는 문법

### 1. ⭐ 변수 두 개로 "어제 / 그저께" 밀고 가기

```python
prev2 = 0     # 그저께까지의 최선
prev1 = 0     # 어제까지의 최선

for x in a:
    rest = prev1          # ① 오늘 쉰다
    work = prev2 + x      # ② 오늘 일한다
    cur = max(rest, work)

    prev2 = prev1         # 하루 밀기: 어제 -> 그저께
    prev1 = cur           #           오늘 -> 어제
```

마지막 두 줄이 이 문제의 핵심이다. **순서가 중요하다.**

```python
prev2 = prev1     # ✓ 아직 안 바뀐 prev1(어제) 을 prev2 로 옮기고
prev1 = cur       #   그 다음에 prev1 을 오늘 값으로 덮는다

prev1 = cur       # ✗ 순서를 바꾸면 prev1 이 먼저 덮어써져서
prev2 = prev1     #   prev2 에 "어제"가 아니라 "오늘"이 들어간다 → 답이 틀린다
```

### 1-1. 파이썬다운 한 줄 버전 (참고)

파이썬에는 **오른쪽을 전부 먼저 계산한 뒤 왼쪽에 나눠 담는** 문법이 있다.

```python
prev2, prev1 = prev1, cur
```

오른쪽 `(prev1, cur)` 를 먼저 묶어놓고 대입하므로 **순서 걱정이 없다.**
같은 원리로 임시 변수 없이 스왑도 된다.

```python
a, b = 1, 2
a, b = b, a        # a=2, b=1
```

짧지만 처음엔 헷갈리니, **익숙해지기 전까진 두 줄로 쓰는 게 낫다.** 결과는 같다.

### 2. 슬라이딩 변수로 DP 배열 없애기

```python
prev2 = 0          # dp[i-2]
prev1 = 0          # dp[i-1]
for ...:
    cur = ...      # dp[i]
    prev2, prev1 = prev1, cur
```

점화식이 **바로 앞 두 개만** 참조하면 배열 전체를 들고 있을 필요가 없다.
`dp = [0] * n` 으로 짜도 정답이지만, 이렇게 하면 메모리가 O(N) → **O(1)** 이 된다.

영어권 인터뷰의 단골 팔로업 "Can you do it in O(1) space?" 의 답이 정확히 이 패턴이다.
피보나치, 계단 오르기, House Robber 전부 같은 방식으로 줄일 수 있다.

**주의**: 나중에 "어떤 날을 골랐는지" 경로를 복원해야 하면 배열이 필요하다.
값만 필요할 때 쓰는 최적화다.

### 3. `max()` 로 둘 중 큰 쪽 고르기

```python
cur = max(rest, work)
```

`max` 는 인자를 몇 개든 받아서 가장 큰 값을 돌려준다. 리스트를 넘겨도 된다.

```python
max(3, 7)           # 7
max([3, 7, 5])      # 7
max(3, 7, 5)        # 7
```

한 줄로 붙여 쓸 수도 있지만, **이름을 붙여 나눠 쓰는 쪽이 읽기 쉽다.**
```python
cur = max(prev1, prev2 + x)      # 같은 뜻. 익숙해지면 이렇게 써도 된다
```

### 4. 배열 DP 로 쓴다면 (같은 문제, 다른 스타일)

변수 두 개 대신 배열을 통째로 들고 가도 정답이다. 점화식이 눈에 더 잘 보인다.

```python
dp = [0] * n
dp[0] = a[0]
if n > 1:
    dp[1] = max(a[0], a[1])

for i in range(2, n):
    dp[i] = max(dp[i - 1], dp[i - 2] + a[i])

print(dp[n - 1])
```

`range(시작, 끝)` 은 **시작 포함, 끝 미포함**이다.
```python
range(5)          # 0 1 2 3 4        (0부터)
range(2, 5)       # 2 3 4            (2부터 4까지)
range(5, 0, -1)   # 5 4 3 2 1        (거꾸로, 세 번째가 증가폭)
```
`i` 가 2부터 시작하는 이유는 `dp[i-2]` 를 써야 하기 때문. 0과 1은 손으로 채워준다.

### 5. ⚠️ 음수 인덱스는 에러가 아니다

위 코드에서 `i` 를 0부터 돌리면 `dp[-2]` 를 읽게 되는데, 파이썬은 **에러를 안 낸다.**
`-1` 은 맨 뒤, `-2` 는 뒤에서 두 번째를 뜻하기 때문이다.

```python
dp = [0, 0, 0]
dp[-1]        # ✗ 에러가 아니라 맨 뒤 값(0)이 나온다 → 버그를 못 찾는다
```

그래서 DP 문제에서는 **앞에 더미를 하나 끼워 1부터 맞추는** 방법을 많이 쓴다.
```python
a = [0] + 실제값들       # a[1] 이 1일째 → 지문의 "i일째"와 인덱스가 일치
dp = [0] * (n + 1)
```
이러면 `dp[i-2]` 가 음수로 내려가는 사고를 막을 수 있다.
