# Q05 파이썬 문법 노트 🐍

> 공통 문법은 [`SYNTAX.md`](../SYNTAX.md) 참고.

## 이 문제에 나오는 문법

### 1. 배열 DP — 점화식을 그대로 코드로

```python
dp = [0] * n                 # dp[i] = i일째까지의 최대 성과
dp[0] = a[0]
if n > 1:
    dp[1] = max(a[0], a[1])

for i in range(2, n):
    dp[i] = max(dp[i - 1], dp[i - 2] + a[i])

print(dp[n - 1])
```

핵심은 마지막 점화식 한 줄이다. **오늘(i일째) 할 수 있는 선택은 딱 둘.**
- `dp[i - 1]` : 오늘 **쉰다** → 어제까지의 최선 그대로
- `dp[i - 2] + a[i]` : 오늘 **일한다** → 이틀 연속은 안 되니 **그저께**까지의 최선 + 오늘 성과

둘 중 큰 쪽이 "오늘까지의 최선"이다. `dp` 배열을 쓰면 이 점화식이 **눈에 그대로 보인다.**

### 2. 초기값 — 왜 dp[0], dp[1] 을 손으로 채우나

점화식이 `dp[i-2]` 를 참조하므로, `i` 가 2 이상일 때만 안전하다.
그래서 **0일째와 1일째는 직접** 채운다.

```python
dp[0] = a[0]                 # 첫날은 일하는 게 이득 (성과가 0 이상이니까)
dp[1] = max(a[0], a[1])      # 첫 이틀은 붙여서 못 하니 둘 중 큰 하루만
```

`if n > 1:` 은 통나무가 한 개뿐(N=1)일 때 `a[1]` 이 없어서 나는 에러를 막는다.

### 3. `range(2, n)` — 왜 2부터인가

```python
for i in range(2, n):        # 2, 3, ..., n-1
```

`range(시작, 끝)` 은 **시작 포함, 끝 미포함**이다.
```python
range(5)          # 0 1 2 3 4
range(2, 5)       # 2 3 4
range(5, 0, -1)   # 5 4 3 2 1   (세 번째가 증가폭)
```
0과 1은 이미 손으로 채웠으니 **2부터** 시작한다.

### 4. `max()` 로 둘 중 큰 쪽 고르기

```python
dp[i] = max(dp[i - 1], dp[i - 2] + a[i])
```

`max` 는 인자를 몇 개든 받아 가장 큰 값을 준다. 리스트를 넘겨도 된다.
```python
max(3, 7)           # 7
max([3, 7, 5])      # 7
```

### 5. ⚠️ 음수 인덱스는 에러가 아니다 — DP의 함정

`i` 를 0부터 돌리면 `dp[i-2]` 가 `dp[-2]` 가 되는데, 파이썬은 **에러를 안 낸다.**
`-1` 은 맨 뒤, `-2` 는 뒤에서 두 번째를 가리키기 때문이다.

```python
dp = [0, 0, 0]
dp[-2]        # ✗ 에러가 아니라 뒤에서 둘째 값이 나온다 → 버그를 못 찾는다
```

그래서 초기값을 손으로 채우고 `range(2, n)` 부터 도는 것이다.
(더미를 앞에 하나 끼워 1일째부터 `dp[1]` 로 맞추는 스타일도 많이 쓴다)

## 참고 — 변수 2개로 O(1) 공간 만들기

점화식이 **바로 앞 두 개(`dp[i-1]`, `dp[i-2]`)만** 참조하므로, 전체 배열 없이
변수 두 개로도 된다.

```python
prev2, prev1 = 0, 0
for x in a:
    prev2, prev1 = prev1, max(prev1, prev2 + x)   # 어제→그저께, 오늘→어제
print(prev1)
```

`prev2, prev1 = prev1, ...` 는 **오른쪽을 전부 먼저 계산한 뒤** 왼쪽에 나눠 담는
파이썬 문법이라 순서 걱정이 없다 (임시 변수 없이 `a, b = b, a` 스왑도 같은 원리).

메모리를 O(N)→O(1) 로 줄이는 최적화지만, **점화식이 한눈에 안 보여** 처음엔 헷갈린다.
영어권 인터뷰의 단골 팔로업 *"Can you do it in O(1) space?"* 의 답이 이 패턴이다.
**배열 버전으로 먼저 이해한 뒤** 이걸 얹는 순서를 권한다.
