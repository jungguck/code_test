# P01. 내림차순 정렬 ⭐ (브론즈)

## 문제
N개의 정수가 주어진다. 이 수들을 **내림차순**으로 정렬해서 한 줄에 공백으로 구분해 출력하라.

## 입력
- 첫째 줄에 N (1 ≤ N ≤ 100,000)
- 둘째 줄에 N개의 정수 (-1,000,000 ≤ 각 수 ≤ 1,000,000)

## 출력
- 정렬된 수를 한 줄에 공백으로 구분해서 출력

## 예제 입력
```
5
3 1 4 1 5
```

## 예제 출력
```
5 4 3 1 1
```
