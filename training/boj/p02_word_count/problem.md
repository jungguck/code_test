# P02. 가장 많이 나온 단어 ⭐⭐ (브론즈~실버 / 해시)

## 문제
N개의 단어가 주어진다. **가장 많이 등장한 단어**를 출력하라.
등장 횟수가 같은 단어가 여러 개면, 그중 **사전순으로 가장 앞선** 단어를 출력한다.

## 입력
- 첫째 줄에 N (1 ≤ N ≤ 100,000)
- 다음 N개의 줄에 단어가 하나씩 (영소문자, 길이 1~20)

## 출력
- 조건을 만족하는 단어 한 개

## 예제 입력
```
6
apple
banana
apple
cherry
banana
apple
```

## 예제 출력
```
apple
```

## 예제 2 (동점이면 사전순)
```
4
zebra
apple
zebra
apple
```
→ 출력: `apple`  (둘 다 2번, 사전순으로 apple 이 앞섬)

## 힌트
- `dict` 로 횟수를 세고
- `max()` 에 `key=` 를 잘 주면 한 줄로 끝난다. (횟수는 큰 게, 단어는 작은 게 이김)
