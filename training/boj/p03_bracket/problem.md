# P03. 괄호 검사 ⭐⭐ (실버 / 스택)

## 문제
`(`, `)`, `[`, `]`, `{`, `}` 로만 이루어진 문자열이 주어진다.
괄호가 **올바르게 짝지어져 있으면 `YES`**, 아니면 `NO` 를 출력하라.

올바른 괄호 문자열이란:
- 여는 괄호와 닫는 괄호의 **종류가 같고**
- 짝이 **올바른 순서**로 닫히는 것

## 입력
- 첫째 줄에 테스트 케이스 개수 T (1 ≤ T ≤ 100)
- 다음 T개의 줄에 문자열 하나씩 (길이 1~1,000)

## 출력
- 각 테스트 케이스마다 `YES` 또는 `NO` 를 한 줄씩

## 예제 입력
```
5
()
([])
(]
((()))
([)]
```

## 예제 출력
```
YES
YES
NO
YES
NO
```

## 힌트
- 리스트를 **스택**으로 쓴다. 여는 괄호면 `push`, 닫는 괄호면 `pop` 해서 짝이 맞는지 확인
- 끝났을 때 스택이 **비어있어야** YES
