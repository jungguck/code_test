## 입력 / 출력
P01 과 동일. N개의 정수를 내림차순으로 한 줄에 출력.
- **N ≤ 50,000**

## 핵심 함정 ⚠️
버블 정렬 / 선택 정렬로 짜면 **무조건 시간초과(TLE)** 난다.
- 버블: 비교 횟수 ≈ N²/2 = **12억 5천만 번** → 파이썬으로 약 5분
- 병합: 비교 횟수 ≈ N·log₂N = **78만 번** → 0.1초

즉 이 문제는 *"정렬을 직접 짜라"* 가 아니라
**"O(n²) 말고 O(n log n) 정렬을 직접 짜라"** 는 문제다.

## 병합 정렬 (merge sort) 원리

**분할정복**: 반으로 쪼개고 → 각각 정렬하고 → 합친다.

```
[3, 1, 4, 1, 5]
   쪼갠다
[3, 1]        [4, 1, 5]
   또 쪼갠다 (길이 1이면 그 자체로 정렬된 상태 = 종료조건)
[3] [1]       [4] [1, 5]
   합친다 (merge)
[3, 1]        [5, 4, 1]
   합친다
[5, 4, 3, 1, 1]
```

**merge 가 핵심**: 이미 정렬된 두 리스트 `L`, `R` 을 합칠 때
양쪽 맨 앞만 비교해서 큰 쪽을 꺼내 붙이면 된다. 한 번씩만 훑으므로 O(n).

```
L = [5, 3]   R = [4, 1, 1]
     ^            ^          5 vs 4 -> 5     결과 [5]
L = [3]      R = [4, 1, 1]
     ^            ^          3 vs 4 -> 4     결과 [5, 4]
L = [3]      R = [1, 1]
     ^            ^          3 vs 1 -> 3     결과 [5, 4, 3]
L = []       R = [1, 1]      L 이 비었으니 R 나머지 통째로 붙임
                             결과 [5, 4, 3, 1, 1]
```
