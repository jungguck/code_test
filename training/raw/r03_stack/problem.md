## 스택이란 뭔가

**LIFO (Last In, First Out)** — 마지막에 넣은 게 먼저 나온다. 접시 쌓기.

파이썬 리스트의 `append`/`pop` 은 *스택처럼 동작하는 편의 기능*일 뿐이고,
스택 자체는 **고정 크기 배열 + 맨 위를 가리키는 인덱스 하나**면 끝난다.

```
data = [_, _, _, _, _]    top = -1      (비어있음)

push('(')  ->  top 을 0 으로 올리고 data[0] 에 쓴다
data = [ ( , _, _, _, _]  top = 0

push('[')  ->  top 을 1 로 올리고 data[1] 에 쓴다
data = [ ( , [ , _, _, _]  top = 1

pop()      ->  data[1] 을 읽어서 돌려주고 top 을 0 으로 내린다
data = [ ( , [ , _, _, _]  top = 0
                ^ 값은 그대로 남아있지만 top 아래니까 "없는 것"으로 친다
```

**핵심**: pop 은 값을 지우지 않는다. `top` 을 내리기만 하면 그 칸은 자동으로 쓰레기가 된다.
`top == -1` 이면 비어있는 것. 이게 배열 기반 스택의 전부다.

## 괄호 짝은 dict 없이 어떻게?

두 문자열을 같은 순서로 나란히 두면 인덱스가 곧 짝이다:

```
OPEN  = "([{"
CLOSE = ")]}"
         ^^^ CLOSE 에서 몇 번째인지 찾으면, OPEN 의 같은 자리가 짝
```
`")]}".index(']')` 는 `1` 을 주고, `"([{"[1]` 은 `'['` 다. 짝 완성.
(`.index(` 와 `in` 은 이 문제에선 허용)
